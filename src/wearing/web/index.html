接入新的电脑或手机

先在设备所在电脑的 Pajio 连接器导出设备清单，再选择交给我的设备和能力。手机通过 USB 连接这台电脑。

如何导出设备清单？

需要先安装 Pajio、完成电脑或 Android 的本机授权。已准备好的连接器可运行：

wearing connector inventory --data-dir 本机数据目录 --offer --output wearing-devices.json

Mac 和 Windows 使用同一条命令。当前仍需命令行安装；iPhone 控制尚未开放。

下载配对文件

配对文件从生成起 10 分钟内有效。带回设备所在电脑，完成配对并安装常驻连接；之后无需保持终端打开。

wearing connector pair --root 新连接目录 --data-dir 本机数据目录 --bundle wearing-pair.jsonwearing connector service install --root 新连接目录

电脑需保持登录、联网和唤醒，手机需保持 USB 连接。连接建立后点“重新查看”。新接入一种设备时，可在没有进行中操作时更新能力。

查看或停止本机连接wearing connector service status --root 新连接目录wearing connector service stop --root 新连接目录wearing connector service start --root 新连接目录

停止会等待当前动作交回回执，配对和历史记录保留。Windows 常驻仍待真机验证。

有一步，需要你看一下

旧动作的结果不明，后续点击和输入暂时停下来。请先查看设备，确认发生了什么；核对会保留原记录。

暂停和离线时会怎样？

暂停会立即停止云端派发，设备随后确认。已经发出的操作可能仍会完成。恢复只允许新的动作，结果不明的旧操作需要核对。

电脑可以观察，也可以按任务连续点击与输入。电话、邮箱与支付方式需要分别接入；iPhone 控制尚在规划中。

录屏列表里找不到 CuaDriver

在 macOS 的「录屏与系统录音」上方列表点击 ＋，按 ⌘ ⇧ G，粘贴下面的应用路径。选中 CuaDriver 后点「打开」，再开启它的开关。

驱动保存在 Pajio 的运行目录，不一定会出现在「应用程序」中。无需开启下方「仅系统录音」。

    
接管时会发生什么
你可以随时接管。Pajio 会停止新的电脑读取和操作；已发出的点击可能仍需片刻返回。交回后会重新观察窗口再行动。
电脑操作复用 Hermes 与 Cua Driver。当前接入的是运行 Pajio 的这台电脑。Mac 需要 CuaDriver 的辅助功能和屏幕录制权限；Windows 接入沿用同一驱动，但尚未完成真机验收。

  

  
你的手机

  
连接 USB，解锁手机，并允许 USB 调试。

  
每部接入的手机都可以单独使用、暂停和恢复。中文填写支持可识别的 Android 原生输入框。

  

  

  

  

  
手机没有出现授权弹窗
打开手机的开发者选项与 USB 调试，保持屏幕解锁后重新插拔数据线。小米设备若能看画面却不能点击，还需检查“USB 调试（安全设置）”。
Android 通过 USB 调试接入，无需插 SIM 卡或 root。不同品牌的附加授权会在实际操作时确认。暂停会拦住后续动作，已发出的操作可能仍需片刻返回。

  
其他 Android 和 iPhone 呢？
Android 使用通用调试协议，接入后逐项确认读取、点击、滑动和输入。当前真机验证为小米 6X（Android 9）。iPhone 控制连接器尚未接入，需要单独的信任、开发者模式及签名配置。
