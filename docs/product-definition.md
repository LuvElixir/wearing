# Wearing 产品定义 v0.5

> 2026-10-03 更新：产品关系与整合价值继续有效，部署形态已转为 SaaS：云端 Agent 核心、租户隔离、设备连接器与云端沙盒。当前状态及计划以 [SaaS 实施基线](saas-architecture-2026-10-03.md) 和项目 README 为准；下面的初版进展、不能插实体卡及早期图形描述保留为历史记录，不代表当前实现。

更新：2026-10-02。以“整合成熟能力，并把真实使用中的每个环节走通”为产品主线。名称与主视觉方向已确定，首个本地开发版已实现。Mac/Windows 与手机是主要执行资源，云端沙盒作为按需辅助资源，实际设备与业务验收继续推进。

## 一句话定义

Wearing 整合成熟 Agent、真实账号与执行设备，把经过验证的开通、接入和维护流程做成软件，让用户更快拥有一个能持续替自己办事的个人 Agent。

## 与用户的关系

“属于我的行动者，同时也是延伸出去的另一个我。”

Wearing 承接用户的目标、偏好和决定，使用获准的资源推进事务，带回可核对的结果。用户决定经营方向、投资策略与重要取舍，Agent 在既定范围内负责日常推进。随口灵感先进行有限预算的初步研究，主动性来自上下文、业务事件与约定的跟进。

## 我们建设的产品价值

成熟项目承担模型调用、推理、工具执行、记忆等通用 Agent 能力。Wearing 重点完成三件事：

1. **把路走通。** 亲自验证用户从现有条件出发，怎样获得邮箱、号码、电脑、手机、支付与业务资源，完成真实任务并长期使用。
2. **把经验变成软件。** 将稳定步骤固化为条件检测、引导、配置程序、连接器、验收测试和故障恢复工具，减少下一位用户的摸索与手工操作。
3. **把资源组织成一个持续工作的 Agent。** 用户通过 Wearing 选择、绑定、查看和接管资源；同一项事务可以跨电脑、手机、API 与账号继续推进。

技术整合包括代码，也包括经过验证的供应渠道、适用条件、材料清单、人工步骤和长期维护办法。方案在真实用户条件下完成并能复现，才构成可交付能力。

## 用户可以选择怎样接入

设备和服务通过连接器接入：云端沙盒、本地 Mac/Windows、远程电脑、浏览器、手机、邮箱、电话服务、支付工具和业务平台均可有不同实现。每条实现公开自己的条件、能力、费用与限制。

用户可以自带已有资源，按已验证流程开通第三方资源，或在未来使用 Wearing 提供的托管资源。产品按资源能力和任务要求匹配组合，不预设所有设备或账号都可互换。

## 每种能力的产品交付

| 交付 | 用户获得什么 |
| --- | --- |
| 适用条件 | 知道自己的地区、身份、设备和现有资源能用哪条路线 |
| 开通与配置流程 | 清楚材料、费用、顺序，以及需要本人完成的步骤 |
| 连接器 | Agent 能调用已经授权的实际资源 |
| 自动化与检测 | 可重复的安装、配对、配置、健康检查和恢复 |
| 验收结果 | 区分资料核实、已开通、已连接、业务通过、持续运行与他人复现 |
| 日常维护 | 到期、失效、重连、找回、迁移、解绑与资源退出都有路径 |

## 目标场景

| 场景 | 真实结果 |
| --- | --- |
| 海外数字事务与订阅 | 适用资格成立，账号和必要资源接通，权益与扣款可核对，后续续费或取消有路径 |
| 网店经营 | 商品、订单、库存、客服与收款在用户确定的经营范围内持续推进 |
| Google 广告 | 账号、计费、追踪、发布和日常调整可以按既定范围执行并核对 |
| 策略执行 | 用户策略落实为可验收的流程，模拟与实盘条件分别确认 |
| 灵感与研究 | 从上下文形成有限任务，带回依据，后续能够继续 |

这些场景用于检验整合是否成立；目标能力尚未在本项目中实测通过。

## 从我们自己到后续用户

先以自身条件跑通一条实际任务链，保留所有步骤和失败经验；随后让另一套设备或另一位用户复现，将反复出现的步骤自动化。稳定后可提供自带资源、辅助配置和托管资源等交付方式。

自建小机房是未来托管连接器的一种供给方式。扩展前先验证资源隔离、远程接管、重置和恢复、成本及迁移；设备租赁与个人实名账号的归属分别管理。

## 当前条件和第一步

已有闲置 MacBook Air，属于独立执行设备；芯片、系统和权限在接入时检测。首台手机为 Android 9 小米 6X，可通过 USB 连接，不能插实体卡；设备操作和号码通信分别解决。海外号码、支付及业务账户资格仍需完整验证。

首版采用 Hermes 主 Agent + Wearing 任务控制与设备接入，优先走通用户的电脑和手机，Daytona 沙盒按需接入。0.1 已有本地工作台、任务持久化、Hermes HTTP 适配与设备检测；实际模型运行、设备操作和跨工具接管尚待验收。邮箱/号码/支付的取得流程同步推进，再逐项串入适用的真实业务。提供商和连接方式按实际验收结果替换，详见整合落地总方案。

## 品牌

统一名称 Wearing，中文说明“你的个人 Agent”。视觉采用已选第 1 个钴蓝卷袖角色，独立小标志简化为头部与折领。完整角色用于状态与反馈，产品界面突出实际进展和成果。
