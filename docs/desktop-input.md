# 按任务连续操作电脑

Wearing 使用已配对的电脑连接器，在用户交代的任务内连续执行。用户可在首次普通动作时选择「交给 Wearing」，然后把过程留给它处理，对话旁始终可以接管。

当前一份任务授权覆盖原任务、原 run、原 MCP 会话、同一电脑和应用，最长 30 分钟、最多 100 个普通动作。完成、停止、目标修订、接管、设备重连、权限版本改变和不明回执都会阻止继承授权。下一件事不会沿用旧授权；换应用、期限或步数用完时重新交托。

每一步先观察目标窗口，使用新 `frame_id`、实际元素序号和原样标签。后台生成每个动作的短期执行凭证，设备在输入前重读 AX 界面，核对连接、控制权和动作摘要。执行回执写回原任务，Wearing 再观察验证实际结果；同一次界面不能重复使用。

普通浏览、填写和滚动声明 `checkpoint=routine`。发送内容、支付下单、删除、账号安全修改和接受新协议声明 `commitment`，显示关键动作确认，批准后同一轮继续。缺失声明默认关键动作；敏感按钮标签和按键提交另有强制检查。语义判断依赖模型，标签拦截只提供额外保护，当前方案不能保证任意第三方应用都可放心无人值守。

用户决定由官方 MCP elicitation 绑定到认证引擎的实际任务。服务器只有在记录用户的任务授权并取得首步回执后，才给同一 MCP 会话挂接授权；同时查询数据库，必须只有这一个活动运行。模型输入任务 ID、伪造 MCP accept、另一个会话或重启进程都不能继承授权。

界面只显示交托或关键动作卡片，普通动作回执留在任务审计中；每次点击不会再生成需要用户处理的卡片。结果不明时暂停且不自动重试。

真实 Mac 独立测试完成一次授权后的三步：填写、点击、再次填写，最终文字及按钮效果分别由新 AX 快照和独立 UI 读取验证。原任务只有一个 run 和一次确认。正式云端电脑输入权限是否已启用，以实际设备列表为准。Windows、跨应用授权和跨天持续目标授权尚待验证。
