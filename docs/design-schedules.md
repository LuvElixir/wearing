# 到时我来：既有记录面板的主动安排

## 范围与方向

2026-10-05，既有 Wearing 视觉世界的窄幅延伸。继承 seed `b2a311f4`，设计复核 disposition 为 `ship`。本文记录源码中的设计与交互；本轮文档记录不新增浏览器或真机验收。

- **THESIS:** 记住用户交代的意图，到约定时间继续行动，并把结果带回来。
- **OWN-WORLD:** 已有钴蓝、近白、系统中文阅读字体、圆角原生字段、细分隔线与安静文字入口。
- **STORY:** 先看会做什么、何时做，再创建、修改或暂停；表单保留一个保存动作。
- **FIRST VIEWPORT:** 进入「一起记着的」侧面板后，「到时我来」位于目标与进展之前；最近行动在详情内按需展开。
- **FORM:** 继承现有世界与组件，不新增视觉概念稿或品牌材料。

实现依据：`src/wearing/web/schedules.css`、`schedules.js`、`index.html`；共同材料与覆盖关系由 `style.css`、`comfort.css` 和根目录 `DESIGN.md` 提供。功能行为与验证边界见 [主动安排说明](personal-proactivity.md)。

## 阅读与操作顺序

列表整行可打开。名称用中等字重，下一行显示约定、状态和下次时间；长名称允许折行。空列表直接说明可在聊天中交代，也可在这里安排。创建入口是「添个安排」，新建提交为「交给 Wearing」，编辑提交为「保存安排」，取消是安静文字动作。

表单先收名称和自由指令，再收一次性或重复时间；重复选择包括每天、工作日、每周及自定规则。时区可见，日期、星期和自定规则随选择出现。「错过时间怎么办」折叠呈现宽限时长及超时跳过的说明。示例文案只帮助理解输入，不构成领域工作流模板。

详情先显示名称、时间、时区、状态、原指令和下次时间，再提供修改、暂停后续／恢复、结束安排。编辑已暂停的安排后仍然暂停，保存反馈说明需要恢复才会执行。「最近的行动」使用原生 `details`，每条显示时间与真实结果状态；「Wearing 已回应」和「结果已核对」分别呈现，无需打扰的检查只显示安静结果。

## 材料与尺度

使用根系统的 `blue`、`blue-deep`、`blue-light`、`page`、`surface`、`ink`、`muted` 与 `line`。名称与状态是文字层级，颜色不承担唯一的状态表达。列表悬停使用浅钴蓝，保存动作继承主要按钮；不增加投影或装饰动效。

本 surface 的章节为 17px / 600，列表名称为 15px / 500，时间与状态为 12px / 1.6；详情标题为 20px / 1.6，正文为 14px / 1.8。表单标签为 13px / 1.6，输入与选择器为 15px / 1.6。指令框受既有记录面板样式影响，实际为 15px / 1.8、14px × 16px 内边距；不超过 600px 时指令文字为 16px。这些是局部阅读映射，未扩充根系统字体层级。

开放记录行以细线分隔，垂直内边距为 18px；字段沿用 14px 圆角。表单用浅色面与 24px 圆角分组，常规内边距 22px。局部表单底色 `#f2f4fa`、普通字段 placeholder `#696f7e` 和一次性间距仅留在实现与本记录；指令 placeholder 继承 `muted`。它们没有新增全局 token。

时间字段保持两列与可收缩宽度。不超过 540px 时表单内边距为 18px、列间距为 12px，输入与选择器为 16px。标题入口保持不压缩；保存与详情文字动作保留至少 44px 的高度。540px 是此表单的局部适配，不替代全局断点。

按钮、输入、原生折叠入口继续使用既有可见键盘焦点。指令框继承记录面板的聚焦边框和轮廓，普通按钮继承 Comfort 的状态反馈；减少动态效果规则继续生效。打开安排沿用界面的滚动偏好，不新增动画。

## 能力与状态边界

已实现的表面针对时间安排及对话工具。「暂停后续」处理未来触发，已开始的本轮停止入口在现有对话。关闭网页与后台服务运行是两个状态；页面按实际部署写明本机服务或私人服务需保持运行，结果回到对话。

记录变化唤醒已追加到同一表单；系统推送与第三方事件源仍未交付。安排历史的模型回应不自动标为业务核对成功；具体执行和结果证据以功能说明为准。
