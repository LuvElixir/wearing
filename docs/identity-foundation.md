# Wearing 身份第一版

2026-10-03。产品入口叫「身份」，英文概念为 Wearing ID。用户可以取名「日常」「出海」「我的店」。同一个 Wearing 按当前身份继续对话、执行和留下结果。

## 已实现

- 创建、改名、修改用途及使用范围；每个标签页单独选择身份，刷新会记住选择。
- 每个身份有独立的消息列表、任务归属、Hermes 会话、Hermes Home（含记忆目录）和文件空间。
- 任务创建时固定 `identity_id`，不可在运行中改归属。切换页面不转移任务；仍保持全局单任务执行，其他身份的进行中事项会显示跳转入口。
- 所有 API 请求携带 `X-Wearing-Identity`；文件下载用显式 `identity` 参数。任务读取、停止、审批、核对等接口验证归属。不存在的身份不会回退到默认身份。
- 前端切换有响应代际检查，旧身份尚未返回的请求不能覆盖新身份页面。未发送的输入按身份保留在当前标签页内存，刷新不保留草稿。
- 日常身份沿用原有会话、文件、电脑及手机。新身份不获得手机或电脑连接器，只能使用自己目录的文件工具。
- 电话、邮箱、支付、收款明确显示待接入。创建身份不创建外部账号，也不会自动改变设备中的登录状态。

## 数据与执行

`identities` 保存名称、用途、范围及稳定 ID。`tasks.identity_id` 是创建时确定的归属，`identity_conversations` 保存各身份当前的上游会话 ID；`messages` 通过 task 关联身份。没有全局“当前身份”变量。

默认身份 ID 为 `daily`，保留 `.wearing/hermes` 与 `.wearing/workspace`。其他身份使用 `.wearing/identities/id_<uuid>/hermes` 和其 `workspace`。Hermes 安装及文件连接器二进制共用；模型选择与支持的 API Key 共用，凭据不返回浏览器，也不复制到新身份的 `.env`。新身份不会复制原身份的记忆、工具配置、账号资料或会话数据库。

额外身份引擎首次发送时启动。除默认引擎外，最多保留一个额外身份进程；另一个身份需要执行时，空闲进程退出，其状态由各自目录持久保存。运行恢复按任务记录里的身份找执行端，不重发原任务。

## 迁移与恢复

首次迁移前保存 `wearing.before-identities.sqlite3`，同时保留原来的 singleton `conversation` 表用于核对。事务内建立身份表、复制旧会话 ID、给原任务增加 daily 归属。迁移可重复执行，不覆盖迁移后的会话进度。

本次现场另有 `.wearing/backups/identities-20261003-025404/`，包含变更前的源文件与数据库。正常使用后若要回滚，先另备份当前数据库，不能直接用旧备份覆盖新产生的消息。

## 当前边界

这是同一用户的应用上下文分隔，不是操作系统、网络或对抗恶意本机进程的安全沙盒。当前设备归属规则固定为默认身份；新身份设备分配、浏览器登录容器、电话/邮箱绑定、支付凭据保管、预算执行尚未实现。不会用切换名字冒充账号切换或海外资格。

初版模型复用覆盖当前界面支持的 API Key 配置；第三方 OAuth 登录没有跨身份复用保证。共同偏好尚未自动共享，避免把旧记忆带入新身份。

- 79 项 Python 测试通过，包含旧数据库迁移、会话同步不串身份、任务与文件接口隔离、改名不转移任务、运行客户端固定及全局互斥。
- 现有动画行为测试通过，保留已批准角色、视频循环与无播放控件。
- 真实独立引擎启动成功，探测到 6 个文件工具、0 个手机工具、0 个电脑工具；共享 DeepSeek 配置可读。
- 隔离的开发验收身份通过一次真实模型调用，成功写入并读回 `identity-check.txt`，回复包含正确身份名；验收记录留在 `.wearing/identity-acceptance/`，没有向用户的两个身份添加测试对话。
- 原有 5 条任务、4 条消息、17 条事件及旧会话字段与变更前备份逐项一致。
- 真实页面完成「出海」创建、来回切换、草稿恢复检查；原四条消息完整保留在日常。
- 本轮实际浏览器宽度 852px；移动端样式已适配，未在手机浏览器真机验收。
