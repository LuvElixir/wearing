# 全球工作 AI 与个人 Agent：品牌研究及本产品决策

研究日期：2026-10-07。此文件与 [可交互研究册](brand-research.html) 一起阅读。详细取证见 [个人助手研究](global-personal-agent-brand-research.md) 与 [工作 AI 研究](global-work-ai-brand-research.md)。

## 判断先行

本产品适合走 **有性格、能办事的个人 AI 品牌**。名称轻、好叫，交互认真、结果清楚；用户可以随时交代事情，再回来接着处理。品牌不需要靠名称解释全部功能，也不需要绑定某个作息时段或某个玩偶。

上一轮方法的问题，是从“省时间、可靠、温暖”等抽象价值直接组合名称。这样的词可能解释得通，却缺少口语里的生命力，也没有足够明确的记忆形象。应当先设计读音、称呼感和辨识度，再检查名字能否承载产品价值。这是本项目的设计判断，不是声称所有年轻用户有同一种偏好。

## 案例透露了什么

| 名称机制 | 案例 | 真正值得学习的地方 | 需要接受的代价 |
| --- | --- | --- | --- |
| 可呼叫的短专名 | Kimi、Lindy、Sana、Omi | 名字容易进入“让它帮我做一件事”的口语；主品牌下可以增加新能力 | 短名称竞争密集；中文听写、读法和检索都要检查 |
| 有具体画面的普通词 | Granola、rabbit、Dot、Comet | 名字先给人一个记忆入口，副标题负责解释用途 | 普通词会有检索歧义；不同文化里的联想也不同 |
| 与行为、思想或工作有关的词 | Cursor、Notion、Linear、Perplexity；另观察 Manus 的独立命名方式 | 可以建立能力联想，品牌延展到新功能时仍保持一致 | 有些名字发音或拼写成本高；概念感不自动等于亲近感 |
| 可直接读出的缩写 | Pi | 极短名称仍能有清楚的解释，官方将其展开为 personal intelligence | 短字母组合难以独占，也未必适合中文语音使用 |

以上是语言与品牌机制分析。除 Pi 外，本轮未核实这些品牌的原始取名动机，因此不把事后联想写成创始故事。Perplexity 也提醒我们：两音节是适合本项目的候选规则，并非行业成功公式。

### 重点参考的五个对象

- **Kimi：名字与功能分层。** 官方品牌材料同时覆盖 Work、Code 等能力；短名称可以保持稳定，能力由产品层说明。我们也应把“搜索、研究、处理文件、安排事情”等含义放到实际入口。[官方品牌手册](https://www.kimi.com/en/resources/kimi-brand)
- **Lindy：可亲近的工作身份。** 当前官网以 AI teammate 和具体工作场景解释价值。可以借鉴自然称呼与明确动作的组合；官网效率数字属于营销主张，本轮未验证。[官方产品页](https://www.lindy.ai/)
- **Granola：有性格，也适合认真工作。** 官方升级文章和设计方材料呈现手绘识别、鲜明传播材料与安静的产品界面。我们应把品牌个性集中到字标、构图、少量颜色和语气，给长内容留足阅读空间。[官方升级说明](https://www.granola.ai/blog/a-new-look-for-granola) · [Ragged Edge 原始案例](https://raggededge.com/partnerships/granola)
- **Sana：身份是一套使用规则。** 官方规范让字标承担主要识别，图形标记服务紧凑场景；字体和配色分别有体系。我们选中的单颗四角星还需要字标、尺寸、留白和明暗用法才能组成完整 VI。[官方品牌规范](https://brand.sanalabs.com/)
- **Cursor：名称可以简洁，能力可以持续增加。** 官方明确写法是 Cursor，品牌规范区分二维、较大场景的立体版本和应用图标。值得借鉴的是具体的使用规则。[官方品牌规范](https://cursor.com/brand)

另外，Notion 展示了人物插画与严肃工作入口如何共存；Linear 展示了信息秩序如何形成成熟感。rabbit 是角色与产品物件的参考。Dot 已在官网公告关停，作为历史设计案例处理；不能把它当作当前商业成功证据。[Notion AI](https://www.notion.com/product/ai) · [Linear 品牌规范](https://linear.app/brand) · [rabbit](https://www.rabbit.tech/) · [Dot 官方公告](https://new.computer/)

### 三个主流品牌，作为校准

研究范围还补充 Claude、ChatGPT、Gemini，共 17 个参照。Claude 是人名式名称，ChatGPT 带有技术描述结构，Gemini 是独立概念名；它们本身就说明没有统一的命名公式。

Claude 在主品牌下使用 Code 等能力名。官方 Cowork 页面可以观察到米白、深色文字与陶土色放射标记；本文不推断其原始命名动机。[Claude 官方产品页](https://claude.com/product/cowork)

ChatGPT 通过 agent、deep research 等描述解释工作能力。这里参考的是品牌和能力名称的关系；OpenAI 的母品牌字体规范不能直接当作整个 ChatGPT 产品的界面规范。[Agent 官方说明](https://help.openai.com/en/articles/11752874-chatgpt-agent) · [Deep research 官方说明](https://help.openai.com/en/articles/10500283-deep-research-faq/)

Gemini 覆盖独立应用与 Workspace 等工作场景。Google 将其标记称为 spark，并说明 2025 年 6 月采用四色渐变设计。这进一步说明，我们的单颗四角星必须与最终字标、轮廓和使用方式共同形成身份。[Workspace 官方说明](https://workspace.google.com/solutions/ai/) · [Google 官方设计说明](https://blog.google/company-news/inside-google/company-announcements/gradient-g-logo-design/)

## 新的命名 brief

**优先方向：可以直接称呼的独立专名。** 两音节左右，读起来干净，字形有辨识度，略有性格。中文读法与拉丁字母拼写同时设计；中文口述顺畅是硬条件，英文形式本身不是加分理由。

**第二条探索线：日常具体词。** 选择有记忆画面、不过分幼态、能延展到工作与生活的词。名字可以有轻微幽默或意外感，解释必须自然。候选数量控制在少量，避免用大量弱选项制造选择负担。

名称应放进四种真实使用情境：

1. “让 ___ 帮我准备一下。”——别人听一次能否复述。
2. “___，把刚才那件事接着做完。”——呼叫与识别是否顺畅。
3. 手机桌面、App 商店、收到结果的通知——没有故事解释时能否记住。
4. 搜索、输入、次日回忆——是否混淆同类产品，是否容易拼错。

候选先过产品与品牌碰撞检查，再过读音、记忆和语音测试。名称进入最终 VI 前，需要进一步检索商标近似及目标市场名称可用性；普通搜索不能代替注册审查。本轮研究尚未选定最终名称。

## 品牌与 VI 的直接决定

| 层次 | 设计方向 | 验收方法 |
| --- | --- | --- |
| 定位 | 能替人推进事情的个人 AI；工作、生活均可使用 | 首次体验后，用户能否说清楚可以交代什么 |
| 个性 | 聪明、利落、好接近；有一点个性，回应具体 | 文案能否直接说明下一步；用户是否敢再次交代 |
| 标志 | 单颗四角星；字标承担主要识别，星用于紧凑身份触点 | 16–32 像素可辨、单色可用、与同类完整组合不混淆 |
| 字体 | 中文阅读优先的现代无衬线；字标可独立定制 | 连续阅读、数字对齐、中文与英文混排 |
| 日间 UI | 中性浅底，正文清晰，少量强调和状态色 | 对比度、长内容阅读、不同屏幕和亮度下实测 |
| 夜间 UI | 石墨深底、柔和浅字，保留表面层次 | 真实夜间使用与系统设置；不把“深色”直接宣称为护眼 |
| 品牌传播 | 允许更有力的色彩、字号和构图，保留鲜明记忆点 | 缩小后是否仍可辨认品牌；是否符合产品真实能力 |
| 角色 | 小熊作为可选个性化；默认品牌在无角色时完整成立 | 喜欢和不喜欢角色的用户都能顺畅完成任务 |
| 动效 | 只帮助理解接收、处理中和结果返回；遵循减少动态设置 | 是否提高状态识别；是否干扰阅读、录音或操作 |

四角星属于常见图形。独特性要靠最终字标、比例、配色、语气及稳定使用共同形成；不能把一个通用形状当作已经完成的品牌差异化。

## 语气与体验

品类说明可以直接写“帮你做事的 AI”。传播主张需要在功能和人情味之间找到自己的句子，本轮不提前锁定最终 slogan。休息场景可以作为传播主题，产品主品牌覆盖全天。

在实际界面里，温度来自清楚而体贴的回应：

- 接收：“收到，我来整理。”
- 处理中：“找到 3 份资料，正在比对。”
- 缺少信息：“还差预算，补一句就能继续。”
- 返回：“整理好了。先看这 3 个结论。”
- 无法完成：“这一步没完成，资料已保留。”

状态文案必须由真实状态触发。用户离开后仍能继续推进，回来能立即看到结果、未完成项和需要自己决定的事情，这是品牌承诺的实际依据。

## 证据与后续验证

本轮完成的是公开品牌研究与设计决策。核查依据包括官方品牌页、产品介绍、官方公告、设计机构原始案例，并保存四组官网视觉截图。部分页面仅核实文字，Perplexity 的视觉材料为 2023 年设计案例，均已在研究册标注。未登录试用全部竞品。

“市场上有人这样做”只能证明存在可参照的方法，不能证明适合我们的用户。下一轮候选应找符合目标使用场景的人测试无提示复述、读音、次日回忆、产品用途理解与任务交代意愿。先用小样本淘汰明显问题，再通过真实使用观察结果可读性与再次交代的比例；本轮没有把内部偏好、融资或官网好评当作市场验证。

本轮交付：研究册、原始来源记录、命名 brief 与 VI 决策方向。最终名称、定制字标及整套 VI 仍待基于这个 brief 设计和验证。
