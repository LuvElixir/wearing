# Wearing 生活工具设计记录

日期：2026-10-04。适用范围：`src/wearing/web/index.html` 的生活工具区域，以及 `life.css`、`life.js`；继承的品牌、对话、身份和目标规范以根 `DESIGN.md` 为准。

## Overview

命名规则（2026-10-06）：手机端与网页端对用户统一显示「任务」，包括回看导航、页面标题、记录类型和辅助说明；内部记录类型、接口字段与已保存的清单名称保持原值。

随手记下一点内容，再为一件小事留时间或放进清单。记录与 Wearing 的连续对话使用同一个已有品牌世界；今天页的构图属于生活工具 surface，不是新的品牌首页规则。

## Colors

近白页面、白色书写面、浅钴蓝选中态与深钴蓝交互文字均继承根文档。蓝灰 `life-field-label` 仅用于表单标签。编辑区背景、输入边框、焦点描边及 Monarch 日历细节保留在组件样例；组件局部材料不自动成为全局色板。

## Typography

页面标题采用系统栈、600 字重、1.4 行高与轻负字距；章节和编辑标题保持 600 字重。记录行正文、字段和主要操作使用 `life-body`，快记使用 `life-capture`，记录类型、摘要和辅助操作使用 `life-label`。记录标题为 500 字重，时间采用等宽数字；说明、时间和帮助保持 12px。

手机页面标题缩至 27px，章节标题为 17px，副说明与导航为 13px。清单组标题的 16px、笔记标题的 15px 与日历内部尺寸各自服务局部层级，不替代既有对话尺度。

## Layout

五个入口置于字标与身份上下文之后。导航最大宽度 1000px，桌面居中，手机靠左并允许横向滚动；所有入口保留不换行的短标题。导航粘性顶距依次为 100px（默认）、88px（≤900px）、78px（≤600px）、0（≤420px），仅适用于当前页眉组合。

内容最大宽度 1140px，默认左右内边距 40px，≤900px 为 26px，≤700px 为 20px。今天的日程与待办两栏间距 36px；≤700px 改为一栏、间距 24px。编辑区桌面宽 340px、栏间距 32px；≤900px 缩至 300px、间距 20px，并将今天的两栏内容收为一栏。≤700px 编辑区进入普通流、排在记录之前，占满内容宽度，输入的日期字段仍可并列。

手机初始日历视图在 JavaScript 的 `<700px` 条件下使用 `listWeek`；CSS 在 `≤700px` 将每一天改为日期条在上、事件在下。事件区域保持全宽与零最小宽度，标题与时间分行并允许长词折行。月、周、一周安排和回到今天保留视图按钮。

## Elevation & Depth

快记以边框聚焦，列表以细线区分，编辑区以浅蓝色面建立层级，均不加投影。生活区域的可见焦点为 3px 外描边、3px 偏移；快记 textarea 由整体钴蓝边框表达焦点。快记边框过渡为 150ms，按钮继承全局 150ms 的 `cubic-bezier(.16,1,.3,1)`；全局减少动态效果规则仍生效。

## Shapes

主导航与保存按钮沿用 14px；记录类型、日历视图与编辑字段使用 12px；编辑区为 16px，快记为 18px。勾选标记为 22px 圆角方形（8px），置于 44px 独立点击区域中；勾号使用内联 SVG。今日头像容器桌面 64px、圆角 22px，手机 52px、圆角 18px；该显示值仅限今日头像，不改变资产或完整角色轮廓规范。

## Components

- **导航与视图选择：** 未选中为说明灰，主导航悬停浅中性底，选中为浅钴蓝底与深钴蓝字。主导航用 `aria-current="page"`，记录类型和视图使用 `aria-pressed`。
- **快记：** 白底、细边框、整体圆角，默认内边距 `18px 20px 12px`，手机为 16px。多行输入在上，三种记录类型与「记下」在下；选择日程后显示开始和结束字段。不要给这三个类型增加卡片包装。
- **记录行：** 日程与待办采用 `16px 0` 的开放行与底部分隔线。标题按钮最小高度 44px，时间独立对齐；待办的完成按钮与编辑按钮各自可达。已完成项呈现钴蓝勾选和划线说明灰标题。
- **笔记行：** 标题、最多 140 字摘要及更新日期依次排列；摘要保留换行并允许长文本折行。悬停或当前笔记标题为深钴蓝。
- **编辑区：** 浅蓝背景、20px 内边距，白色字段、细边框与 12px 圆角。标题、内容、日期或清单归属按记录类型出现。保存与「和 Wearing 聊这条」使用既有主要／次要按钮；移除保持较轻文字入口。
- **反馈与冲突：** 保存反馈使用浅钴蓝，错误使用问题红文字与轻红底；所有反馈有可见文字。冲突保留输入，并单独展示最新版本及重新编辑入口，不以成功颜色掩盖失败。
- **日历：** Monarch 主题通过局部 CSS 变量映射 Wearing 颜色。最后生效的容器样式为无边框、透明背景和零内边距，不依据前面的白色边框声明新增一张卡片。事件点击进入同一编辑区；视图控制保持圆角文字按钮。日历默认按钮最小高度与宽度 40px，手机高度 44px；手机事件点击区最小高度 64px。系统提醒尚未接入的文字保留。
- **回到对话：** 编辑后或保存反馈可带记录标题进入既有对话上下文条；草稿由用户继续编辑，记录标题也可重新打开原记录。这个关系沿用目标上下文材料，不引入新的身份选择。

## Do's and Don'ts

- **Do** 保留列表的开放阅读密度、真实保存反馈与现有品牌资产。
- **Do** 让手机日历完整显示日期、标题和时间；修改日历覆盖样式时核对最后生效声明。
- **Do** 保留 44px 的生活导航、常规操作和待办点击区域，以及字段标签和焦点反馈。
- **Don't** 把日历内部的按压色、今日头像圆角或当前页眉粘性偏移推广为全局规范。
