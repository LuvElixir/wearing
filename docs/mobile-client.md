# 手机客户端增量 · 2026-10-04

本轮交付 `clients/mobile`：React Native + Expo 57.0.26，复用成熟的相机、录音、文件、SQLite、时间选择和 WebView。没有改变 Wearing / Hermes 核心的部署责任，也没有恢复云机。

## 已实现与验证

同一套 RN 源码提供「今天、安排、笔记、和你聊」。随手文字、选图、日程创建、待同步状态、原话/原件查看及在线编辑已在独立测试服务的网页适配中实际验收；两条离线文字/图片记录在重新打开后保留，恢复服务后生成两条唯一记录，图片字节与输入原件一致。编辑后的同一记录在 Wearing 原网页显示 revision 2。另创建一条合成日程，进入共享安排。

两项真机兼容修复已落实：等待 SDK 57 的异步文件复制完成才确认留存；原件上传转为 bytes，保留明确的 MIME，避免无扩展名 UUID 文件的空类型覆盖请求头。

生产源代码通过 TypeScript 检查，15 项针对离线、重试、身份和恢复的核心测试通过；Web、Android、iOS 运行资源导出通过。Android 原生工程生成及 Manifest 检查通过，包含相机和录音权限，禁止系统自动备份及通用存储/悬浮窗权限。**资源导出和配置检查不等于可安装 App，也不等于真实手机验收。** 当前主机没有 Android SDK/JDK 或完整 Xcode；用户重连小米 6X 后，已通过官方 Expo Go 57.0.9 加载本项目原生界面。实际验证 Android 9 的 SQLite 离线新建、强制结束后重开、恢复连接只同步一份记录，以及拍照和录音保存、重开后继续上传。相机与麦克风均由用户授权，测试媒体只送到隔离本机服务，关闭模型整理。Expo Go 是开发宿主，尚无 Wearing 独立 APK/IPA。

预览：[手机客户端代码预览](http://127.0.0.1:8787/)。普通 Wearing 入口仍为 [本地版](http://127.0.0.1:8765/)。预览是本机开发服务，不能用于公开 SaaS 登录。

## 本机与共享记录

原生使用 `expo-sqlite` 持久保存草稿、快照、待同步与回执；图片/音频复制进 `Paths.document/originals`。网页适配采用 IndexedDB 及 Blob，单独检验记录协议与 UI。不能用浏览器验收代替 SQLite 或 MIUI 权限证明。

队列和草稿以「规范化服务地址 + 身份」分区。加入队列和清空输入使用一次数据库事务。上传原件及创建记录使用稳定 request key；响应丢失时重放，不生成第二份记录。已上传的 asset ID 持久保存，重启后可接着上传。完成回执在取到服务器快照前仍留在本机，包含删除状态的快照防止已经移除的记录复现。

前台每 15 秒和重新激活时尝试同步，单次网络请求 20 秒上限。临时错误退避，六次失败停止自动重试；验证/权限/冲突错误立即留作待处理，用户可重试。每次新建最多四份原件、每份 15 MB，队列最多 100 条。暂停期间保留数据，不制造已完成反馈。

图片选择、录音停止和上传绑定最初身份；切换后不把原件归入新身份。切换需先保留录音与草稿。未保存成功的录音在当前页面中可重试，**强制结束进程后的录音恢复尚未实现**。记录详情的对话 URL 携带已验证身份、记录 ID 和 revision，不携带笔记正文；原网页取当前记录并恢复上下文，不自动发送消息。原网页在 bootstrap 后核对该身份，再加载对应对话；这只是已有身份选择，不创建账号、不赋予资源权限。

现有记录编辑携带 revision，冲突不覆盖服务器数据，输入保留。离线编辑既有记录、合并冲突与全量后台同步未实现。

## 原生权限与连接

仅在拍照/录音时请求对应权限；选图使用系统选择器。Android release 网络配置只允许 HTTPS 和本机回环 HTTP，USB 调试通过既有 ADB 授权及 `adb reverse` 连接本机 Wearing。没有开放局域网明文例外。开发 debug Manifest 的 SDK 默认行为与正式 release 分开验收。

Android 9 已验收相机、麦克风、文件留存、SQLite 断网重启及回连；没有据此推定 iOS 或其他 Android 设备可用。iOS 的 ATS、本地网络授权，以及录音中断、真机内存、系统字体放大、图片格式转换仍待检查。手机原件保存在 OS 私有应用目录，SQLite 没有应用层加密；删除/保留期限、迁移与私有原件清理策略仍需产品化。禁止自动备份是当前 Android 配置，不能推定 iOS 也已验证。

当前仅保存服务地址、身份和业务数据；bootstrap token 只保存在内存，过期后重取。远端必须 HTTPS，拒绝地址里的凭据、查询、路径和 hash。公开服务仍需已规划 OIDC 登录，当前本地 bootstrap 不能当作生产账号认证。

旧机 WebView 对话仍有明确缺口：小米当前 WebView 74.0.3729.136 显示网页外壳，但没有完成记录上下文初始化。现代浏览器继续聊已通过，不能算作这台手机的对话验收。
