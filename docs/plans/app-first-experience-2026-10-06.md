# App 体验优先

2026-10-06。用户确定 App 是下一阶段主战场。目标是让用户从一个念头出发，顺畅输入、理解结果、作出判断，再回到生活；采用 Wearing 的近白、墨灰、钴蓝和既定 3D 角色。

## 设计与模型的分工

| 层 | 产品固定的基础 | 每次任务的自由空间 |
| --- | --- | --- |
| 原生 App | 导航、身份、键盘、安全区、返回、保存与恢复 | 展示哪一份对话、记录或结果 |
| 设计系统 | 字体层级、语义颜色、控件状态、触控范围、动效与可访问性 | 布局密度、视觉重点、媒介与信息组织 |
| 生成结果 | 自包含文件、隔离呈现、真实依据、版本与验证状态 | 图表、关系图、交互实验、数据模型、计算与内容 |

模型先读按需设计指引，再编写实际问题需要的页面。共享控件可组合，缺少的控件沿用规范实现；不按外卖、旅行、账单等业务穷举模板。生成页面中的变化首先是探索，真实行动通过有上下文的 Agent 能力执行。当前结果无主应用调用通道。

## 已交付的第一步

- 四类共享控件：组合输入、原生滑轨、关闭、折叠。宿主与内联指引用同一份 CSS。
- 结果打开时焦点落到标题；关闭保持 44px 点击范围，视觉面缩小，展开箭头反映真实状态。
- App 对话使用 `host=mobile` 隐去重复品牌、身份和生活工具导航；保留文件、记忆与连接入口。
- WebView 外层补原生加载、慢连接提示、失败重试。重试由用户触发，不自动重载正在编辑的页面；身份或连接变化重新创建对应页面。
- 禁止嵌入对话自动跳到异源和系统协议；身份与记录引用保持现有边界。显示参数不代表权限。

## 2026-10-06 连续性增量

普通标签切换保留已打开的同身份对话 WebView，回到对话不再因条件渲染主动销毁输入、滚动和展开的结果；连接或身份改变仍清除旧实例。从原生端传入单向的可见性信号，隐藏或进入后台时停止网页轮询和陪伴动画，并收起键盘。页面不可通过此信号取得原生权限。

源码类型、lint、客户端测试及 Android/iOS 资源导出通过。尚未在原生设备验证页面保留、键盘与前后台；记录上下文变化仍会重新创建页面；新增本机草稿恢复见下一段，原生系统回收后的实际恢复仍待验证。浏览器窄屏验证不代替这些真机验收。

## 2026-10-06 输入恢复增量

网页及 App 内嵌对话按身份、普通对话、目标及讨论模式、生活记录分别保存本机草稿。刷新后恢复文字和原讨论对象；服务确认收下消息才清除对应内容，发送期间写的新文字保留。离开页面和进入后台会尽力立即保存；存储不可用时明确提示，当前页面仍保留输入。普通对话与目标草稿的刷新、切换和发送后清除已在浏览器验证。

恢复在服务 bootstrap 成功后进行，尚不支持离线冷启动；草稿只在同设备、同源保存，没有跨设备草稿同步，多窗口同时编辑同一主题也尚未合并。原生 WebView 被系统回收、键盘与返回链路仍需真机验证。

## 接下来的顺序与完成标准

| 顺序 | 完整操作链路 | 完成标准 |
| --- | --- | --- |
| 1 | 打开对话 → 输入 → 查看结果 → 返回继续聊 | 键盘不遮输入；返回不丢草稿、消息位置；原生返回与页面关闭一致；中断可恢复；手机首屏可看懂结果 |
| 2 | 拍一下 / 说一句 → 确认原件 → 整理 → 继续聊 | 相机返回不丢原话；录音中断和权限拒绝可恢复；存本机/同步中/已保存清楚；只在真正完成时反馈 |
| 3 | 主动进展 → 通知 → 查看 → 决策 | 推送直达正确身份与原任务；未读状态跨端一致；安静时段有效；用户一次处理后不会反复提醒 |
| 4 | 跨端继续、离线与系统入口 | 同一记录版本可核对；断网不吞输入；同步冲突保留两边修改；分享、日历、辅助功能有真实系统验收 |

第一步原生化先拆出对话与结果路由，明确草稿和滚动状态的所有者，再迁移输入器与结果查看器。复杂生成页面仍适合放在隔离 WebView 中，外部导航、返回、错误与分享由原生界面处理。避免一次性重写全部生活工具。

## 每条链路的体验验收

- 每个状态一个明显主要行动，次要操作逐层展示；控件至少 44 点命中范围。
- 手指操作有即时可见反馈，等待状态不伪造进度；需要测量首屏可用时间和输入到反馈延迟，当前尚无真机性能基线。
- 动画表达位置或状态变化；中断后能继续，遵守减少动态。触觉反馈只用于有意义的确认与边界，不逐次装饰震动。
- 验证大字体、读屏、深浅系统环境、软键盘、系统返回、前后台、断网、重复点击和进程重建。未验证的设备单列。
- iOS 与 Android 分别验收，不拿浏览器窄屏截图证明原生手感。签名安装包、系统推送及 iOS 真机仍待交付。

## 当前技术边界

手机生活记录已有原生实现，对话仍是嵌入网页。尚未完成原生对话输入、原生结果路由、返回手势与草稿跨进程真机验收。Android/iOS 导出只证明资源可打包，不代表原生安装与运行验证。

在线小米 6X 是 Android 9，系统 WebView 74；现代网页兼容性不能由新浏览器结果推定。后续先核定可支持的 WebView 版本与更新路线；旧机是否可更新和新设备/iOS 验收分开推进，不为适配一台设备限制整体产品。
