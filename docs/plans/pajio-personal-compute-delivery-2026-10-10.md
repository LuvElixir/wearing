## 完成的定义

一个外部测试用户能在 Pajio App 使用属于自己的 Linux 电脑与 Android 手机：交代任务、查看真实进展、接管输入、断线后安全恢复、交还后继续；另一个用户不能看见或控制其设备、文件、账号或画面。服务离开开发 Mac 仍运行。费用、队列、故障状态可解释。

2. **国内应用逐个验收**：飞书、B站、小红书、抖音、微信按官方安装、本人登录、只读任务、重启保持、人工接管记录结果。先确认 ARM/GMS/平台兼容，不能直接把所有平台作为已支持功能宣传。

4. **小范围开放**：沿用 operator 准入、显式配额和已验收应用，完成发行签名、有效 iOS 渠道、独立包体下载与备案接入核验后开放对应入口。

## 原始上游候选

- UI-TARS 的桌面 operator 与坐标规范（Apache-2.0）：按需独立评估；Linux 首版可用已有 Python/X11 工具，不引入整个 Electron App。
- Open-AutoGLM 的 ADB 执行层（Apache-2.0）：与现有设备通道对比，强制设备 ID，截图失败必须报错，禁用输入内容日志。
- OpenMuse 的 ComputerBackend 生命周期设计（MIT）：借鉴接口，适配自有 Proxmox，不照搬其公网桌面 URL。
- Android 首轮 redroid 或 Cuttlefish：在独立执行 VM 里运行；ADB 不开放公网。镜像/第三方 ARM 翻译组件的许可与实际 App 兼容性单独记录。

## 接管硬性契约

1. 请求绑定账户、身份、connector、resource、session、epoch；设备 ACK 后才能显示可控。
2. 用户接管先使 Agent 许可失效，再取得设备输入锁；旧 Agent 命令不能继续。
3. 画面与输入通过单独鉴权、端到端加密的 WebRTC 通道；信令服务不保存媒体/键盘内容。
4. 每次输入验证控制权、当前画面几何与有效期；不重放离线积压输入。
5. 失联、过期、撤权、切账户、App 后台立即停止输入并保持暂停，不自动恢复 Agent。
6. 用户离开敏感界面、明确交还，设备清理媒体缓存并 ACK，Agent 重新观察再执行。
