# Wearing 首页减法与轻薄输入栏 · 2026-10-06

范围：`clients/mobile/src/experience/` 交互预览。用户提供豆包截图作为参考，明确要求独立判断，保持 Wearing 身份。此次不改真实业务服务或账户。

## 设计判断

首页核心仍是表达意图，同时露出值得看的进展；避免把 Agent 的主动性变成首页信息堆积。既定 3D 角色、钴蓝和独立身份延续，未照搬参考的分区或推荐入口。

- 一个居中的角色与输入邀请，保留短句和声纹的单次提示动画；删除问候、气泡说明和重复的开始提示。
- 原方案大卡收成一个进展入口，下一条日程安静排列在下方。详情从结果页查看，简报转入次级目录，回看入口保留。
- 语音栏视觉高度 48px，麦克风宿主 64px，突出部分依然处于可点击父容器内。侧边图标去除单独底色，完整 44px 点击范围保留。
- 文字模式保持弹性高度；有草稿仍可切回语音，非空时出现发送。无草稿不显示空说明行。

## 验收证据

- 390×844、320×740：实际 browser width 与 scrollWidth 分别一致，无横向溢出，页面层级及文字完整。

- 实际点击麦克风顶部 8px（高于白色轨道上缘）成功进入语音示例面板。

- 更多页面 → 晚间简报 → 返回：首页路径成立。
- TypeScript、ESLint、Web 与 iOS 资源导出通过；独立窄范围审阅无阻塞问题。
