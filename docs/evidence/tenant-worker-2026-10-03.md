# 独立租户 Worker 验收

日期：2026-10-03。范围：S1 私有 Worker 工程入口及本机双进程集成。**不是 VM 隔离或公共 SaaS 上线验收。**

## 本次实现

- `wearing tenant init/status/serve`：不可变实例归属、私有数据目录及数据卷归属标记，拒绝重新绑定已有目录。
- 所有私有 API、页面、下载及记忆入口均要求每实例内部服务凭据和匹配的租户标识；重复凭据字段拒绝。保留 Origin、Host 和修改操作的 CSRF 检查。
- 每私有卷只启动一个本服务写入者。错误卷和无效引擎配置在打开数据库之前拒绝；错误消息不输出私有配置内容。
- Worker 复用产品 Store、TaskService 和 HermesRuntime，不建立第二个 Agent 循环。已安装引擎自动尝试启动；未配置模型不破坏产品记录。
- 云端模式关闭本机电脑/手机工具自动装配及设备管理入口。远程设备转发尚未接通。
- 提供 Linux VM 的 systemd 模板，当前没有安装或运行该模板。

Python 回归命令：`uv run --offline pytest -q`，168 项通过（6.53 秒）。新增测试位于 `tests/test_tenant_worker.py`，覆盖初始化、归属、私有配置、错误卷、单写者、跨租户入口、Origin/Host/CSRF、消息/任务/文件分隔、重启，以及受管引擎启动与配置故障恢复。现有固定版本 Hermes 适配器、记忆、目标及设备契约回归一同运行，不调用付费模型或实际设备。现有动画检查 `node tests/test_web_motion.cjs` 亦通过；本次没有修改品牌、角色或页面。

## 保留与缺口

用户当前 8765 服务保持运行。原日常/出海身份、5 条任务、4 条消息、17 条事件及原模型配置/密钥文件、记忆文件清单与此前保存基线一致；没有迁移用户目录、替换已固定的 Hermes 或控制已连接设备。

尚无 OIDC、平台会员库、可信入口路由、密钥轮换/撤销、真实 VM/microVM 的 guest kernel/卷/网络证据、设备出站转发、云端持久唤醒或自动备份。因此 `hardware_isolation_verified` 固定为 false；内部服务凭据不等于用户身份认证。两份本地目录不能代替独立 VM。

运行与后续部署要求见 [租户运行入口](../tenant-runtime.md)；完整项目状态见 [当前进度](../progress.md)。
