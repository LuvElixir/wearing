# 真实 App 与已确认设计的接线验收

日期：2026-10-07。范围：`clients/mobile/src/Mobile.tsx` 实际入口，而非 `/experience` 示例页面。

## 问题与改动

用户的 iPhone 截图显示旧 Mobile 页面：无五入口、顶部占位过大、更多为纯文字链接。此前 `/experience` 设计没有接回真实入口，是实现脱节。

- 预览与真实 App 共用 AppDock、BottomNavigation、IntentComposer、Sheet、图标及触摸反馈。
- 五入口：聊天、日历、任务、记忆、Wearing。日历内查看笔记；任务含待办、持续目标与定时。
- 记忆与目标列表只读取当前身份真实数据，保留错误与空状态；没有写入预览示例。
- 同一身份对话页与输入栏保持挂载，草稿跨页保留；切页收键盘。
- 更多为带图标底部面板；相机、附件回到既有原件保存能力。
- 嵌入对话去除重复网站导航，字阶、画布、头像、间距与原生外壳统一。原生欢迎页使用静态角色。
- 修复验收发现的 WKWebView 问题：从日历首开时，display:none 祖先导致加载无法完成，继而禁用语音。改用保持布局的不可见、不可交互容器；隐藏期间暂停网页媒体。

## 证据

在 Xcode 27 Device Hub 的 iPhone Air / iOS 27.0 模拟器，以 Expo Go SDK 57 运行真实根路由，连接本机 Wearing。

1. 日历首开：五入口和原生按住说话栏同时可见；修复后冷重载无需点击重试，语音按钮由禁用恢复可用。
2. 月历从 2026 年 10 月切到 11 月；当前日期图标仍为设备本地 7 日。
3. 实际软键盘输入临时草稿「请问」，切任务页仍保留；随后清空，没有发送或产生 Agent 执行。
4. 记忆页读取真实当前身份，当前两组记忆均为空，未用假资料补齐。
5. Wearing 页显示真实「日常 · 已连接」；更多面板有文件、持续目标、定时、连接和同步图标。
6. 聊天保留原有历史与回执，底部五入口可见。

截图：`native-more.png`、`native-calendar.png`、`native-chat.png`。蓝色齿轮属于 Expo Go 开发工具，不是 Wearing 产品按钮。

## 工程检查与限制

- 移动端 107 个测试通过；类型检查、ESLint 通过。
- WebView 宿主、原生输入桥、回看导航 30 个测试通过。
- iOS 和 Web 资源导出通过；这不是签名安装包或 App Store 构建。
- 这轮没有采集真机录音；不能用模拟器按钮启用代替真实 iPhone 的 ASR、触感、VoiceOver 与后台恢复验收。
- 文件与目标的深层管理仍使用已有 WebView 页面，尚不能声称每个次级页面都已原生重做。
