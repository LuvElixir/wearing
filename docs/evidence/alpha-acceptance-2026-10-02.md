# Wearing 0.1 开发验收记录

日期：2026-10-02。当前开发主机为 macOS arm64；不是用户准备投入使用的闲置 MacBook Air。

## 交付

- Python/FastAPI 本地服务、SQLite 持久任务/进展，原生中文 Web 工作台。
- Hermes HTTP 客户端：能力探测、创建运行、查询、审批透传、停止请求；密钥仅存服务端。
- 稳定任务、会话、运行引用及幂等键。创建请求响应丢失时保留不明状态，不自动再次 POST。
- 重启查询原运行；外部结果与模型运行结束分开记录；人工结案不会暗示远端已被停止。
- 可下载的独立设备检测脚本、ADB 状态解析、目标电脑检测报告导入。
- Mac/Windows/Android/iOS 适配条件、手机与通信分工、当前已知设备更新至项目文档。

## 自动检查

最终功能测试：`uv run pytest -q` → **24 passed**。包含：

- 缺少 Hermes 时保留草稿；CSRF / Origin / Host 校验；凭据输入错误不回显内容。
- 创建超时不重派发；数据库重新打开后使用原运行编号；单个活动任务约束。
- 审批只匹配当前 request_id；停止请求与已停止状态分离；输出需单独核对。
- 异常运行状态、异常审批结构、ADB 未授权与离线状态、无效地址/密钥。

`node --check src/wearing/web/app.js` 通过。`uv build` 构建产物见 `dist/`；wheel 包含页面和角色资产。

上述 Hermes 测试使用 httpx.MockTransport 协议夹具，未调用模型，不构成设备/真实业务验收。
