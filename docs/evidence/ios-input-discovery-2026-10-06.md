# 首页输入可发现性 · 2026-10-06

用户认可已完成的页面结构，但指出输入入口缺少视觉焦点。初版细化了 experience 预览的共用输入区；用户随后明确要求将引导移到首页画面。以下初版记录保留为审阅历史，以第二轮结论为准。

- 原白色工具栏中的语音动作改为唯一实心钴蓝主按钮，文案「点一下，说给我听」。
- 键盘保留图标并增加「打字」，48×56命中区；语音按钮最小56px高。
- 文字模式提示说明发送动作；语音或文字已有草稿时继续显示草稿状态。
- 不新增引导弹窗、自动录音或持续动效，沿用现有轻按反馈与减少动态规则。

验证：TypeScript、直接ESLint、web与iOS资源导出通过；390×844浏览器无横向溢出；文字按钮一次点击自动聚焦；语音按钮打开原示例面板。独立窄范围视觉检查通过。仍为明确标记的设计示例，不是iPhone原生录音验收。

## 第二轮：画面引导，图标操作

用户确认方向：输入暗示应出现在首页画面，按钮保持简洁。

- 新增 `InputInvitation.tsx`，沿用既定 3D 角色；带有「比如，随口一句」标识的示例气泡分三段显现，与小声纹同步，4.4 秒后静止。
- 输入邀请整块可点，与麦克风进入相同语音面板。附件、麦克风、键盘恢复图标形式，保留辅助功能标签与足够命中区。
- 输入、弹层、离焦、后台及滚出提示区域会停止动画。减少动态偏好未返回时保持静态；一次播完不反复循环。
- 声纹属于输入示意，预览没有调用麦克风，仍不能作为真实录音或 iPhone 原生手感验收。

实测：浏览器中示例文字 opacity 从 0.12 变为 1；点击引导进入语音面板；键盘一次点击自动聚焦，切回语音成功。390px 截图可读，页面宽度与 scrollWidth 均为 390。尝试设置 320px viewport 后工具仍返回 390，故本次不把 320px 标作通过。

验证：TypeScript、ESLint、Web 与 iOS 资源导出通过。Web bundle `entry-b25bbff63952667b133ad3ac1f9530ae.js`，iOS bundle `entry-76134aa96dd863a39ae2fcda68fb1c4d.hbc`。独立窄范围源码与视觉审阅无阻塞发现；未生成 IPA 或提交 TestFlight。新增阴影已统一为现有表达入口的阴影值，避免引入额外色值。
