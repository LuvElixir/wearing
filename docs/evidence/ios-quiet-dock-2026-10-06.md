# iOS 预览：常驻输入与五入口

2026-10-06，范围为 `clients/mobile/src/experience`、`src/app/experience/_layout.tsx` 与手机/网页端用户可见的任务命名。本机预览 `http://127.0.0.1:8793/experience`，内容与操作仍为隔离示例。

## 实现

- 常驻 dock 位于路由之外，页面切换不重建输入组件。五入口为现在、日历、任务、记忆、Wearing。
- 语音/文字栏固定 58pt；textarea 固定 44pt，两行显示、内部滚动。语音与文字交叉淡入，切换保留草稿。
- 取消、短按与转写提示在上方绝对浮层内进入/退出，不占底栏布局。路由、失焦、停用和卸载会取消过期手势及示例转写回调。
- 输入使用整体圆角焦点边界，网页预览统一替换默认矩形 outline，仍提供键盘焦点。菜单补图标，主页面标题去重。
- 任务内合并待办、持续目标与定时；日历内回看笔记。真实手机/网页可见 Todo 名称同步改为任务，不改 API 或数据记录类型。
- 页面、分段内容、图标、提示及弹层具有进入与退出过程，遵循减少动态；不对每行内容逐项延时。

## 工程检查与边界

- TypeScript 与修改范围 ESLint 通过；现有33项测试通过，其中14项为手势控制器测试。网页 life.js/schedules.js 语法检查通过。
- Web 与 iOS 资源导出通过；iOS 资源导出不是签名 IPA 或 TestFlight 安装证据。
- 完整 `expo lint` 启动器受到本机 npm 的 ESM/require 错误影响；改用本地 ESLint 对修改范围检查，未宣称整个历史仓库 lint 清零。
- 自动浏览器短按与模式切换已验证；真实触控长按/上滑取消未在 iPhone 验收。取消浮层共用已验证的固定布局，但不将单元测试作为真机触控证据。
- 本预览不请求麦克风、不转写真实语音、不调用 Agent，不更改真实日程和账户。真实录音、系统软键盘、安全区、VoiceOver、触感与系统恢复仍须 iPhone 测试。

本轮结论：预览交互达到恒高、草稿连续、图标导航与柔和状态过渡的验收要求；App 真机体验待接入后单独验收。
