# 公开资料研究验收 · 2026-10-05

## 本轮交付

Wearing profile v12 启用固定版本 Hermes 的原生 `web_search` / `web_extract`。未修改第三方源码、未增加另一套检索或 Agent 循环。新安装默认 Exa 匿名免费层；已有 `web` 配置完整保留。上游免费层可能限流或切换其免费后备服务，不承诺 SLA。工具能力可在“连接设置 → 联网查资料”看见。

宿主在原生 run 进度回调收取查询与工具返回的来源元数据，按真实 `run_id` 留存；模型不能填一个 ID 把来源写到别人的轮次。原生带鉴权的运行查询经过 owner 检查后附加回执，Wearing 保存到对应任务。结果继续是 `completed_unverified`，来源不等于事实核验。

网页回应与“以前留下的事情”有可展开的来源。已读取优先、同 URL 合并；搜索过程另收起。显示来源链接、工具观察时间、缓存和失败提示；正文、凭据和服务商诊断不进入这份 UI 记录。链接限制 HTTP(S)，拒绝凭据、敏感 query 字段和内网字面地址，所有动态文本转义。底层原始正文与缓存仍由 Hermes 管理。

## 真实验收

- 隔离临时身份目录、合成旅行问题，仅复用已有模型凭据。
- 需求：查泉州 UNESCO 官方介绍，找两个值得进一步了解的历史看点，先搜索再读取官方网页；不订票、不推断实时人流或营业时间。
- 真实 Hermes + DeepSeek 返回 `completed_unverified`；2 次查询、10 条搜索结果、2 个网页读取回执，前端合并成 9 个来源。
- 两个已读取 URL：`https://whc.unesco.org/zh/list/1561`、`https://whc.unesco.org/en/list/1561/maps/`。
- 引擎错误凭据查询原运行返回 401；不存在运行返回 404；另一 Wearing 身份查询同任务返回 404。
- 关闭隔离引擎后来源仍可从 Wearing 数据库查看。测试内容未加入用户真实对话、目标或安排。
- 私有原始验收结果位于 `.wearing/qa/research-20261005/live-check.json`；不提交凭据、聊天数据库或完整引擎日志。

## 网络兼容

本机代理将公开域名解析到 `198.18.0.x`，初次读取被 Hermes 原生 SSRF 检查阻止。使用上游已经提供的 `security.fake_ip_ranges: [198.18.0.0/16]` 在本机配置声明虚拟地址段，未启用 `allow_private_urls`。修正后官方网页读取成功；127.0.0.1、10.0.0.1 和 169.254.169.254 仍被拒绝。

此配置仅用于当前已观察到代理行为的本机与隔离验收目录，不是产品给所有部署设置的默认豁免。其他设备按实际网络配置处理；额外身份的引擎目录也需声明其执行网络，当前尚无自动代理检测设置页。
