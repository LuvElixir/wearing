## 展示与版本

桌面 1280px 和窄屏 390px 的真实浏览器已操作。390px 下应用与结果页宽度均为 390px，没有水平溢出，数字输入与结果更新正常。展开视图独立于对话轮询，刷新对话列表不会重建正在操作的 iframe；关闭则销毁预览。

版本 2 使用开发验收脚本把默认预算改成 320 元，验证服务端修订记录与“上一版”入口；这一步不计为第二次真实模型修改验收。浏览器从 v2 返回 v1 后，预算与结果恢复为旧版 350 / 550 / 70。旧文件快照没有被修改。

元数据始终转义，模型生成的 HTML 不进入主页面 DOM。真实隔离测试页尝试读取主页面、访问 localStorage 和 fetch 本机接口，页面均显示“已阻止”。实现同时使用 iframe 的 `sandbox="allow-scripts"` 和响应头 CSP sandbox，不授予同源权限；主应用维持原有 CSP。机制依据：[MDN iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)、[CSP sandbox](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/sandbox)。浏览器隔离不等于执行 VM，也未验收所有浏览器的网络、CPU 或内存滥用边界。

## 本轮边界

- 第一版仅支持 1 MB 内的自包含 HTML，每轮最多 8 份结果；数据、CSS 与 JS 内联。外部依赖和真实业务按钮未接入。
- 依据由 Agent 随产物保存，尚未自动关联到观察回执逐条校验。
- 支持工具读取旧结果并发布新版本、查看上一版；尚无差异视图、关闭后筛选状态恢复、明确选中结果继续聊的界面。
- 下载是原始 HTML 文件，离线打开不继承应用的 CSP 隔离。
- 网页与浏览器窄屏已验收；原生桌面客户端、真实 Android/iOS 中的预览仍需单独验收。
- 视频、PDF 与通用 Markdown 内嵌渲染未交付。
