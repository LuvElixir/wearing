# 任务交托与快速电脑接管验收

日期：2026-10-04。源码及独立测试记录位于 `.wearing/qa/task-takeover-20261004/`，运行期内容未进入安装包。

## 结果

- 普通动作支持一次任务交托，绑定原任务/run、当前 MCP 会话、电脑、应用、连接、控制权及权限版本。默认期限 30 分钟、100 步；后台动作凭证和新界面核对仍逐步执行。
- 原配对支持网页发起、连接器心跳自动同步、持久化待确认、原凭据提交及自动重新连接；手动下载请求不会自动扩大授权。
- 对话旁提供接管；普通执行回执不再形成待处理卡片。关键承诺、范围变化或不明结果仍需介入。

## 实际验收

独立真实 Mac 测试：一次授权、一个 run，执行填写/点击/再次填写三步；新 AX 快照核对最终文字与按钮状态。另由原生 UI 独立读回核对。

真实 DeepSeek + 固定 Hermes/MCP + 浏览器交托 + Mac：两轮各产生三份输入回执及一次用户授权，每轮都使用自己的原 run。第一轮按钮此前已显示已点击，模型如实说明无法从该轮快照证明按钮变化；第二轮重开空白测试窗口，实际看到「等待一次测试点击」变为「点击已验证」，最终输入为「新任务连续完成」。没有操作其他应用、写入正式身份或改动真实配对。

第二轮验收中，首次确认因人工等待过久而过期，没有产生命令；测试版本随后重新申请。观察后增加 `desktop_workflow_stopped` 拦截，同一运行被拒绝、过期或取消后不再生成申请循环。此新增边界由回归测试验证；不把旧测试版本的重申请作为最终行为。

自动权限同步测试覆盖确认回包丢失后的恢复、只提交一次版本、原手机能力保持、历史手动请求不自动交付。任务测试覆盖换应用、关键动作、敏感标签、按键提交、超时、步数上限、另一运行、另一活动任务、停止、接管、重连、权限变更、已排队后撤销和伪造接受。

最终 Python 回归：355 passed，18 skipped（独立 PostgreSQL 环境未启用）。JS 语法及媒体状态测试通过。
