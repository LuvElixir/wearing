# iOS 输入交互预览：2026-10-06

范围：`clients/mobile/src/experience` 与共享 `src/hold-voice.ts`，本地 8793 `/experience`。不录音，不访问真实 API，不修改账号和业务记录。真实录音组件 `VoiceComposer.tsx` 尚未迁入本轮手势。

## 改动

- 一个输入条取代抬高的麦克风与外层容器；中央按住说话，旁边直接切文字、拍照、添附件。
- 删除语音 Sheet。按住、取消和转文字状态在输入区反馈；释放后固定示例句进入可修改草稿，并标明是示例。
- 220ms 启动反馈，600ms 最短有效手势；上滑 64pt 取消、回到 40pt 内继续。短按、失焦、后台、离线、路由退出与卸载不提交。
- 键盘按住 Space/Enter 时阻止所有重复按键默认滚动，窗口失焦取消。原生辅助功能提供 activate/escape。
- 新输入不再混入旅行演示；已有新消息时隐藏旅行来源按钮。首页暂停与确认状态联动；欢迎页移除重复入口。

## 已验证

- `npm test`：33 / 33，通过。其中 14 项是假时钟手势控制器测试，包含短按、长按、提前上滑、滑回、重复松手、失焦取消、dispose、过时计时器与回调重入。
- `npm run typecheck` 通过；针对 experience、路由和 hold-voice 文件的 ESLint 无告警。
- Web 导出成功。iOS 资源导出成功；它不是签名 IPA。
- 浏览器 390 × 844：短按无弹窗并出现提示；切文字、写草稿、切语音再切回来保留原文；发送进入自己的对话，无旅行演示回答。
- 选择周末方案并确认后返回，首页显示“已留出周末时间”。该操作仅改变预览内存状态。
- 浏览器 320 × 740：输入文字和图标完整，无横向溢出（scrollWidth = innerWidth = 320）。

## 验证限制

浏览器自动拖动没有产生可确认的长按完成状态，不能把手势单元测试称为已完成 iPhone 触控验收。长按的界面转换、真实录音权限、录音准备期间松手/取消、中文识别准确率与速度、系统软键盘、VoiceOver、触感及系统回收恢复仍需真机测试。预览固定转写文案不作为 ASR 证据。

按产品规则，真实录音适配后仍应先把结果放入可修改草稿；用户明确发送才进入 Agent 处理。设计依据见 [产品审视](../plans/ios-input-product-review-2026-10-06.md) 与 [手机设计规范](../design-ios-experience.md)。
