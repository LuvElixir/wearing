# 现在、语音输入与回看验收

2026-10-06。基于用户确认：App 默认语音；日历、Todo、笔记用于次级回看与纠正；命名应一眼理解且没有歧义。

## 已实现

- 网页唯一主场为「现在」，去掉五个并列一级目的地。桌面与手机的回看面板提供日历、Todo、笔记，文件、目标与定时任务、连接设置继续可达。
- App 源码默认进入现在，原生语音按钮为主要输入，键盘按钮切换文字。回看使用相同层级；普通切换保留同一对话实例。记录的直接编辑和手动补充仍保留。
- 原生点击开始/停止录音，先保存本机原件，再上传到身份绑定的私有媒体库。新转写接口复用本地 faster-whisper，结果填入同一对话草稿，用户可修正并发送。不因语音输入预设笔记、日程或 Todo。
- 转写按原件缓存；重试不重复识别，不创建生活记录、不自动发送对话。身份错误、非法结果、空语音、并发冲突均保留原件。超时有明确反馈。
- 原生到网页仅注入经过 JSON 序列化的文字与固定回看目标，没有网页到原生麦克风/文件权限桥。等待身份与草稿恢复后才带入语音；重放不会重复追加。隐藏/后台/最长 180 秒停止并尝试保存录音，源码通过构建，真机生命周期另验收。

## 设计复核与后续

清理旧侧栏的占位、手机底部标签留白、身份按钮绝对定位和窄屏隐藏标签。设计检查的字号与圆角提示已修正到现有尺度和 control 变量，没有忽略规则。保留原有角色、视频与统一控件。

App 尚未完成本轮真机麦克风、软键盘、来电/后台、系统回收测试；目前语音识别后仍需发送，不是实时语音对话。拍照/附件直接进入同一意图入口、不同事情聚合、系统通知、费用计量等仍在后续范围，不能以导航改造宣称完整 personal agent 已完成。网页现有明确记录的 MCP 能力保留，没有新增固定场景工作流。
