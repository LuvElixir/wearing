## 实际链路

浏览器通过文件选择器上传测试海报和 WAV，显示原件已保存；「记下」创建一条笔记，后台按读取 → 整理 → 完成更新。模型整理的真实标题为「测试备忘：读书会海报与周末散步录音」，最终 revision 2。独立 API 核对 `kind=note`，没有新增日程。记录通过正常可恢复移除流程归档，原件保留。

Apple Vision 实际读到了「10月11日 14:00-15:30」、街角书店及「这是测试海报，不是真实活动」。合成录音时长 6.84 秒；small 转写仍将「散步」「书店」识别为「散布」「书点」，不能表述为准确转写所有中文。页面保留原录音、原转写和整理正文供核对。

同一条记录通过标准 MCP stdio 的 `life_records` 读取，返回完成状态、两份原件和两段提取来源。HTTP 下载逐字节等于原测试文件，图片/音频在浏览器实际加载。原件 SHA-256：
