# Wearing 个人对话与角色更新验收

日期：2026-10-02。本轮改为以自然、连续的个人对话为主入口。用户指定蓝色挽袖角色，明确画面和文案应表达“我来帮你干”；使用 Hypit 重绘独立资产和制作 720p 动作。此次是本地开发版体验更新，待用户体验反馈。

## 实现与已有数据

- 首页为完整 Wearing 角色、行动语义文案和直接发送的输入框。连接设置、旧事项在次级面板。
- 对话逐条保存原文，对应实际 Hermes 运行；连续多轮共享会话。收到执行端规范 session_id 后，同步尚未送出的消息，刷新和重启保留上下文引用。
- 离线消息明确显示本机已保存，无伪造的 Agent 回复；恢复连接不自动执行旧意图。运行中追加的话也保存，可以依次继续。
- 审批、停止、运行不明、结果核对沿用原有接口。旧任务与事件数据仍保留，未删除用户的设备接入草稿。
- 动画只是角色表达，不能表示设备已连接或任务已成功。
