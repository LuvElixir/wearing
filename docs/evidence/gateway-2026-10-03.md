# OIDC 入口与双实例验收

2026-10-03。范围：新入口服务、会员查询、实例路由与本地完整 HTTP 链路。**身份提供商使用本机合成测试服务，执行真实 RSA 签名、JWKS、授权码和 S256 PKCE 交换；没有登录任何真实第三方账号。**

## 新增交付

`src/wearing/cloud/control.py`、`gateway.py` 与 `wearing gateway init/member/route/serve`。公共入口核对登录与会员关系后添加内部服务凭据，转发到固定租户 Worker。保持每实例自己的 Wearing/Hermes/数据；没有共享 Agent 会话，也没有复制用户模型配置。平台只保存登录、会员、实例路由和临时 OIDC 状态。

## 自动检查

`tests/test_gateway.py` 新增十五项测试。ID Token 使用实际 RSA 签名，由真实 Authlib/JOSE 验证，不用假的“验证成功”替身。覆盖：

- 两用户自己的消息、任务、资产与来源检查；浏览器伪造内部凭据或租户头不能切换实例。
- 错误签名、issuer、audience、期限、nonce，以及 `nonce_supported: false` 不能绕过 nonce 检查。
- 未邀请主体拒绝；另一浏览器的回调拒绝；已使用或过期 state 拒绝，不再次交换 token。
- 登录会话和待完成 OIDC 状态跨入口重启保留；Cookie 只有不透明编号/临时标记，没有提供商 token 或 PKCE verifier。
- 退出与会话过期拒绝旧 Cookie；撤销会员授权立即影响下一次访问；进入另一租户要再次核对会员。
- 错路由由独立 Worker 拒绝；错误凭据引用在派发前拒绝；上游 Cookie 不串用；未知私有入口和超大正文拒绝。
- 不可用 Worker、错误 Discovery 的错误返回不包含私有地址或提供商详情。
- 开发元数据库不能采用用户已有数据库或符号链接到另一份数据；原数据保持不变。

完整回归 `uv run --offline pytest -q --tb=short`：183 项通过（7.73 秒）；上游 Authlib/httpx 兼容导入产生一项弃用提示，没有测试失败。现有 `node tests/test_web_motion.cjs` 动画检查亦通过，本次未修改视觉资产或页面。

## 实际 HTTP 服务

私有记录：`.wearing/qa/gateway-20261003/live-result.json`。本次实际启动一个合成 IdP、一个入口和两个 Wearing CLI Worker，入口重启两次，首次用时 4.2 秒，最终修改后再验通过用时 4.4 秒。仅监听回环地址，测试进程已全部停止。

| 流程 | 结果 |
| --- | --- |
| Discovery → 授权码 → PKCE → JWKS / ID Token → Wearing | A/B 两个测试主体分别进入自己的实例 |
| 发起登录后重启入口再回调 | 服务端 state 与浏览器关联仍匹配，完成一次性登录 |
| 写下想法与文件下载 | 两份原话分别持久保存；读取各自测试文件，另一方消息不可见、任务 404、越界路径拒绝 |
| 浏览器伪造租户与内部密钥 | 入口仍依据当前会员关系进入原实例 |
| 操作者故意把 A 路由到 B | B 的固定实例入口返回拒绝，没有读取 B 的内容 |
| 再次重启入口 | 原 Cookie 可续接原实例、读到原消息 |
| CLI 撤销 A 的会员关系 | 无需重启，A 下一次请求拒绝，B 仍正常 |
| 退出 B 后重放旧 Cookie | 拒绝访问 |
| 日志 | 未出现内部服务密钥或会话签名密钥；没有记录回调 URL |

测试消息保持“已保存、未发送模型”的状态，文件是合成验收内容；本次没有模型调用、电脑/手机操作或真实业务执行。
