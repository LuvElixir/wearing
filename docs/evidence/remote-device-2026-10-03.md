# S2 云端设备验收

日期：2026-10-03。复用首台腾讯云香港 VM，没有新增实例、盘、云数据库或存储桶。云端 Worker 与本机日常 Wearing 的数据各自独立；本轮没有迁移用户聊天、记忆或模型配置。

## 实际通过

1. 本机 Mac 通过公网 HTTPS 主动连接该 VM，正常校验证书、IP SAN 与有效期。公网无设备凭据请求为 401；访问 `/internal/runtime` 为 404。私有 Worker 原有无凭据/错误 tenant/外来 Origin/本地设备 API 依旧为 401/403/403/501。
2. 十分钟配对文件通过现有加密 SSH 通道传入本机；设备凭据单独产生并私有存储。云端 inventory 同时显示 MI 6X 与本机电脑，两项资源在线。
3. 云端动作账本真实派发 Android HOME、打开 `com.android.settings`、读取界面元素、截图。全部收到 `completed` 驱动回执。截图是实际 PNG，137266 字节，SHA-256 `94dd51cf66828751d5a1acc0315f91ad8acd25b8158cab7243f9c219b66a0f76`；内容只存在私有证据/数据卷，不发布到文档。
4. 云端读取电脑驱动状态和真实应用列表，收到 `completed`。没有做远程桌面点击、输入或焦点接管，没有绕过审批。
5. 云端 Wearing/Hermes 发现 12 项远程 MCP 工具。真实 DeepSeek 对话实际调用 inventory、HOME、UiAutomator2 读取桌面，两个设备动作均有完成回执。模型回答的首五项文字与真机返回相符：桌面时间、日期、天气提示、天气和相册。产品任务仍为 `completed_unverified`，没有把回执等同于所有业务场景成功。
6. 本地连接器暂停手机后，云端状态更新为不可用；尝试派发新观察被 `resource_offline_or_paused` 拒绝。恢复之后设备重新在线，手机原绑定及个人数据未改动。
7. Relay 服务多次升级/重启，私有 SQLite 配对与动作账本保留，连接器继续出站恢复。Mac LaunchAgent 实际启动并保持心跳；工作目录/日志改到正确位置后启动成功。未做整台 Mac 重启/重新登录验收。
8. 云端升级并启用远程工具后，原两条部署测试消息、单轮目标、原生记忆标记、验收文件和模型配置与升级前一致。后续新增两轮明确的设备 QA 对话属于本轮测试记录；未迁入真实本机对话。
9. 本机 8765 服务未重启，真实引擎仍可达。个人状态快照前后一致：任务 5、消息 4、事件 17、身份 2、长期目标 0、日常记忆文件 0，模型配置/凭据散列一致。

## 暴露并修复的实际问题

Hermes 使用 MCP SDK 2.0.0，Wearing 连接器环境为 1.x；SDK 字段名与低层 server 注册方式不同。已统一按 wire alias 输出 Schema，增加标准 callback 注册兼容；远程 MCP 运行在 Wearing 自己的解释器。电脑 stdio 程序只加载轻量协议和已有驱动，不再误拉入 managed 环境里不存在的 PyYAML。

首次后台安装造成连接器中断。那轮真实模型按键操作成为 `unknown`，模型没有再次按键，也没有伪造桌面内容。核对本地持久账本确认该编号没有进入执行准入后，才在操作者入口记录人工解除，并开启新的 QA 回合；原命令未重发。这不是整个网络故障矩阵的验收。

心跳只读取一次 `adb devices -l`，不每秒对每部手机串行调用三次 getprop。实际动作仍由原有驱动重新核对 USB 状态、具体资源、设备锁与暂停。

## 软件验证及限制

全套测试 258 项通过；18 项 PostgreSQL 用例因专用 QA 集群未启动跳过，本轮没有改数据库控制面。

对配对竞争、同设备抢租约、跨租户/身份/连接伪造、权限过期、撤销、重复动作、ID 冲突、丢失执行许可响应、崩溃恢复、暂停、取消和 late result 的事务/HTTP/stdio 用例已通过。包内包含公共源码/文档/服务模板，不含 `.wearing`、设备凭据、私有 TLS/SSH 密钥或截图。

试验仍是单租户、30 天固定证书与私有网页 Origin；不是生产 SaaS 上线。VM 常规费用仍为 ¥0.29/小时（计算与两块盘），公网出流量及模型调用另计。没有新增收费云资源，也没有设置自动关机或硬累计费用上限。完整身份/账号隔离、电脑输入审批、公开登录入口、凭据轮换、画面保留策略、第二租户/Windows/其他手机和跨天目标持续推进均待后续验收。

原始证据位于本机 `.wearing/qa/remote-device-20261003/`、`.wearing/connectors/tencent-first/` 与 VM `/var/lib/wearing/remote-device-qa/`，只以私有权限保存。对外文档保留能力/结果，不公开凭据、完整屏幕或账号信息。
