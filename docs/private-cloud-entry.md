# 私人云端网页入口

2026-10-03。同一台腾讯试验 VM 保持独立 Wearing/Hermes 与私有卷。本机新增回环 SSH 隧道和单人网页入口，网页已经可以使用云端对话、目标、文件、记忆及设备状态。原 8765 本地版继续保留；新的私人云端入口为 `http://127.0.0.1:18865/`。

这是当前操作者的私人试用入口，**不是 SaaS 账号登录**。正式登录继续复用现有 Authlib OIDC 与 PostgreSQL 会员/实例路由，不将本功能扩展为共享账号服务。

## 连接方式

1. 通过已验证的 SSH 管理连接，把本机另一个回环端口转发到 VM 的 `127.0.0.1:8765`。SSH 保持主机密钥验证、无密码登录，不转发 SSH Agent，不开放 VM 的产品端口。
2. 把该实例的 `instance.json`、`gateway.key` 和 `data/instance-owner.json` 通过加密管理连接放在本机独立的私有目录。这只复制实例绑定与入口服务凭据，不复制对话、记忆、模型密钥或业务文件。
3. `wearing tenant preview --root <私有入口目录> --upstream http://127.0.0.1:18866 --port 18865`。入口仅监听 `127.0.0.1`；端口必须与该实例已登记的网页来源一致。不能传任意外部上游。
4. 启动后读取私有目录中的 `preview-access.json`，在浏览器打开其中的入口。随机一次性凭据位于 URL fragment，前端立即清除它，通过同源 POST 换成 HttpOnly / SameSite=Strict 会话。凭据十分钟失效，只可消费一次；会话八小时失效，入口重启也会失效。重新进入需重启入口以生成新的私人链接。不要公开这个文件或链接。

内部实例密钥始终在入口服务内。入口复用 OIDC 网关的正文上限、固定 Host/tenant 绑定、路径过滤、视频 Range 转发和 Cookie 丢弃逻辑。未登录的 API 返回 401，`/internal/*` 不转发，修改请求还要通过 Origin 与 Worker 页面令牌校验。无访问日志，无共享缓存。

当前 Mac 的隧道和入口由各自 LaunchAgent 管理，设备连接器继续独立运行。隧道使用原已验证的 SSH 主机记录与密钥，私有副本存于用户的 Library/Application Support；OpenSSH 的含空格路径需在 `UserKnownHostsFile` 选项内加引号。没有关闭主机密钥校验。

## 设备暂停与恢复

网页在“云端已连接”面板列出当前身份已配对的资源，电脑明确标为观察能力。

- `GET /api/devices` 返回连接心跳、实际可用性、暂停状态、控制代次和设备确认是否待完成。
- `POST /api/devices/control` 要求当前身份、页面令牌、资源 ID 与页面观察到的代次。状态过期返回 409；不能操作另一身份的设备。
- 暂停立即拦住云端新的 enqueue/claim，排队动作变为 blocked，执行中动作变为 unknown；已发出的原生动作可能完成，迟到内容被丢弃。
- 连接器从既有 HTTPS poll 收到控制状态，持久保存到本地动作账本，再用当前连接确认。恢复等这个确认后才放行新的动作；重连需要重新确认。
- 本机暂停与原生接管权限仍然优先，云端恢复不能覆盖它们。暂停和恢复不会清除不明动作的人工核对要求，也不会重播旧命令。

设备配对和不明动作核对已进入网页，见[接入说明](device-pairing.md)。完整安装向导、Windows 常驻安装、生产证书与轮换、真实 IdP、电脑远程输入审批及全新 VM 灾难恢复仍需实施。电话、邮箱、支付与收款尚未接入。
