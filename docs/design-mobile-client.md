# Wearing 手机客户端设计记录

2026-10-04。范围为既有 Wearing 随手输入和生活记录的 React Native / Expo 适配。品牌规范以 [根 DESIGN.md](../DESIGN.md) 为准；本记录描述手机表面，不建立新品牌或批准稿。方向依据为 [surface.md](../clients/mobile/docs/surface.md)，实际源码为 `clients/mobile/src/Mobile.tsx`、`brand.ts`、`Conversation.tsx`、`Conversation.web.tsx`、`TimeField.tsx` 及 `TimeField.web.tsx`。

## Overview

沿用近白页面、钴蓝动作、卷袖角色 PNG 和描边字标 SVG。先接住文字、图片和录音，再明确显示它留在本机、正在同步或已进入 Wearing 的哪一阶段。页面延续自然中文，记录与原对话保持同一身份和上下文。

当前 finish reviewer 最终结论为 `ship`，原三项问题已解决：记录继续对话的上下文、编辑失败的真实反馈、空待办清单的说明与入口。此结论针对当前适配和截图复核，不等于正式分发或全部原生能力验收。

## Colors

`Mobile.tsx` 将 Paper primary / secondary 映射到根 `blue`，选中容器映射到 `blue-light`，正文、说明、页面、白色表面、分隔线和错误映射到已有同名颜色。手机选中导航的前景使用 `blue`。录音结束按钮旁的麦克风在录音中采用问题红；时长和「说完了」共同说明状态。没有增加品牌装饰色。

## Typography

记录标题为 17，元信息为 13 / 21，摘要为 15 / 24；快记输入为 17 / 27。数值均为 RN 逻辑单位。正文使用 Paper 的平台阅读字体；品牌字标继续使用矢量轮廓，宽 112、高 30。

当前页面大标题直接使用 Paper `headlineLarge`（32 / 40，并覆盖字重 600），章节用 `titleLarge`（22 / 28），分组用 `titleMedium`（16 / 24），记录详情标题用 `headlineSmall`（24 / 32）。这些是当前组件库实现事实；系统默认展示标题不提升为 Wearing 的品牌展示字体规则，根文档既有问候字体继续有效。

## Layout

- 顶部：字标与身份设置，接着是连接文字与同步动作；反馈紧邻连接行并带 polite 播报。
- 窄屏：四项底部导航为「今天／安排／笔记／和你聊」，内容最小高度 64，图标 22、标签 12；安全区域独立处理。
- 宽屏：宽度达到 840 后同一目的地转为 160 宽左侧栏；内容最大宽度 800，保持可阅读的单列。
- 正文：水平 24、顶部 20、底部 48 的滚动内边距；章节上方 32、内部间隔 8。头像为 76 方形，按原比例 contain。
- 快记：白色边框容器内边距 16；输入最小高度 112、最大 260。媒体动作允许换行，保存主动作最小高度 48。
- 安排：日程以日期时间和标题组成列表，下接清单。空清单保留解释与「记一件待办」入口。

上述尺寸只约束本客户端；原生布局单位并非截图物理像素。手机表面不直接套用网页生活工具的日历网格。

## Elevation & Depth

自定义快记、列表行、底部导航和侧栏以色面与 1 单位分隔线建立层级，没有新增自定义投影。Paper 自身触摸反馈由组件库负责。品牌头像保留原有材质与轮廓；Android 系统栏、Expo Go 浮动入口和系统权限面板属于宿主界面。

## Shapes

快记沿用 18 圆角；本机图片缩略图为 56 方形、12 圆角；底部导航选中区域为 16 圆角。Paper theme `roundness: 4` 是组件库生成形状的输入，不能理解成所有控件的最终半径。图标使用 Lucide SVG 线形，不以文字字形替代。

## Components

### 快记与原件

文字、拍一下、说一句和选图属于同一输入区域；笔记／待办／日程使用三段选择。日程显示开始和结束；原生分别调用系统日期与时间选择器，网页使用 `datetime-local` 字段。原件行显示名称、图片缩略图或麦克风图标，以及「原件已留在本机」。媒体存在时显示是否让 Wearing 整理原件的开关。

### 本机队列与真实反馈

本机队列独立列出标题和状态：等待连接、正在同步或需要再看一下；需要处理的项提供「再试一次」。顶部连接反馈不代替某条记录的保存状态。编辑失败明确说明「修改尚未确认」，保留输入并提示恢复连接后核对；不能仅因出现模型回复或结束加载就显示已成功。

### 记录与对话

记录标题可打开详情，下方保留时间或整理阶段，摘要最多两行。任务同时有勾选和完成划线。详情保留可编辑正文、原话与原件，以及继续对话入口。原生 WebView 加载现有 Wearing 对话；网页预览的入口显示「接着聊：」与当前记录标题。两个平台共用 `conversationLink`，传入当前身份和记录上下文，不重新建立手机专属 Agent 身份。

### Sidecar 样例

`.impeccable/design.json` 追加手机输入、记录行、待同步状态、选中导航和主操作的独立 HTML/CSS 样例。它们用于设计面板展示材料和层级；原生按压、无障碍及平台日期选择器以实际 RN 组件为准，样例不是原生控件替代品。

## Do's and Don'ts

- Do 保留既有品牌材料、自然中文和清楚的状态来处。
- Do 保留空态的创建入口、失败时的内容和继续处理入口。
- Do 让当前记录通过同一身份与上下文继续对话。
- Don't 把离线留存称为服务端成功，或把整理完成称为内容已核对。
- Don't 将当前页面标题的默认系统展示字体、Expo 悬浮入口、系统栏或截图滚动位置推广为品牌规则。
