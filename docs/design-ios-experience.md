# Design System: Wearing iPhone experience

## Overview

本记录从 2026-10-06 已构建的 `clients/mobile/src/experience/` 扩展提取，限定于手机客户端。它继承根 [DESIGN.md](../DESIGN.md) 的 Wearing 身份：钴蓝、近白、中文阅读、已确定的 3D 卷袖角色。Today 截图作为层级、生活感和直接操作的参考，不改变 Wearing 的标志与角色。

Operate 模式：用户说出意图、理解进展、作出一次必要决定，然后回到同一件事。圆润体现在容器、命中区和轻按反馈；顺手体现在少绕路、状态连续和容易返回。首屏内容与业务结果应随真实上下文变化。

`/experience` 是同一 Expo / React Native 客户端中的隔离交互预览，业务内容为示例。2026-10-07 起，真实 App 的 `/` 入口也接入了同一套 `AppDock`、`BottomNavigation`、`IntentComposer`、图标、按压反馈和 Sheet。此前预览已更新、真实 Mobile 页面仍沿用旧入口的脱节，在本轮纠正。

真实 App 读取当前身份的对话、日历、任务、笔记、目标、定时安排和记忆；未把预览示例写进真实数据。语音使用实际录音适配器，转写后进入待发送草稿。文件、目标管理等深入操作仍复用已有嵌入页面；预览里的示例日记、亲密度或简报不能被当作已接通功能。此次交付是 Expo Go 开发版本，不是 IPA / TestFlight；模拟器验收也不能替代真机麦克风、触感和系统手势验收。

源码依据：[原生栈与方向合同](../clients/mobile/src/app/experience/_layout.tsx)、[屏幕](../clients/mobile/src/experience/ExperienceScreen.tsx)、[共用控件](../clients/mobile/src/experience/primitives.tsx)、[局部 token](../clients/mobile/src/experience/tokens.ts)、[示例状态](../clients/mobile/src/experience/state.ts)。本文件不改写其他端的 token。

## Colors

行动钴蓝用于主动作、可操作文字和选中状态；浅蓝为当前内容提供安静底面。近白画布与书写白区分背景、内容及输入区。正文为墨灰，辅助文字沿用说明灰，细线只组织相关内容。

**The iPhone Tint Rule.** 手机体验沿用 Wearing 的钴蓝作为行动色，白与近白承担阅读层级；角色继续使用已确定的真实 3D 资产。

这里没有全屏渐变壁纸或仿玻璃背景系统。局部色面只服务内容与操作，不把每个区块都装饰成新焦点。危险、成功、离线等状态仍须有可读文字，不能仅由颜色表达。

## Typography

原生界面不指定额外字体，沿用平台系统字体及中文回退；iOS 由系统提供 San Francisco / 中文字体。上方 frontmatter 的 `system` 描述这一平台选择，不要求添加同名字体文件。

页面标题明确、正文留出中文阅读行距，对话回应略大于普通记录正文；说明与时间退一级。预览源码没有关闭系统字体缩放，按钮采用最小高度而非固定文字高度。完整 Dynamic Type 大字号适配仍须真机检查，不能把默认字号通过称为全量验收。

**The iPhone Reading Rule.** 原生系统字体承载正文和控件；标题、记录、辅助说明有清楚层级，保留系统字体缩放，不用品牌展示字体承担长篇阅读。

## Layout

「聊天」是表达主场，首页主句为「你说，我来做。」传达语音输入、执行输出；输入栏以「按住说话」提示具体手势。底部常驻「聊天、日历、任务、记忆、Wearing」五个低干扰入口：日历页内回看笔记，任务页查看待办、持续目标及定时安排。设置与简报等补充页面由带图标的菜单进入。实际首屏和示例数据不构成固定业务模板。一个视觉主焦点允许必要的直接入口同时存在。

**The iPhone Intent Rule.** 语音是「聊天」的默认表达入口，文字随时可达；回看用于核对 Agent 整理的记录，不要求用户在说需求前选择记录类型。

原生 `Stack` 负责页面前进与返回，并保留返回手势。屏幕尊重安全区；输入区位于可触达的底部；页面内容独立滚动。`Sheet` 提供键盘避让，内容滚动与抓手手势分开，编辑时不靠整页拖动关闭。

五入口切换保存草稿、分区和记录变化；「聊天」在已有消息时接续当前对话。次级页面保留进入它时的导航归属。预览的进程内状态不能作为生产环境离线持久化或系统回收恢复的证据。

真实 App 在同一身份中保留对话 WebView 与原生输入底座，只替换上方回看内容。隐藏的 WebView 保持非零布局，避免从日历首开时 WKWebView 无法完成初始化；它不接受触摸和读屏焦点，媒体按隐藏状态暂停。切页收起键盘但保留草稿；设置返回进入前的主入口。

桌面上的手机外框、页面目录和它们的宽度仅帮助审阅，不属于 App 导航、断点或设备尺寸规范。

## Elevation & Depth

阅读区域以平面色阶为主。底部输入区以白底和细边线区分近白画布，不另叠一层悬浮容器。分段选择的白色面只有更轻的阴影。Sheet 使用独立遮罩与白色内容面，层级由进入、关闭和背景隔离共同表达。

不把审阅外框的大阴影推广到 App 内容卡片，也不把透明遮罩解释成全局玻璃材质。

## Shapes

共用动作按钮为圆润矩形；图标按钮为圆形，视觉图标小于完整命中区。Sheet 顶部两角比普通控件更圆，读屏和关闭动作仍明确。卡片按内容组织，当前页面中有局部圆角差异；共用 token 给出基本层级，不要求将每个示例卡片的数值复制到所有页面。

**The iPhone Touch Rule.** 图标按钮命中区至少 44pt；主要按钮最小高度 52pt，允许随文字增长。视觉尺寸不能缩小实际可点范围。

## Components

### 表达入口

首页的角色与一句输入邀请构成中心，示例短句伴随小声纹分段显现；短句的提示动画在 4.4 秒后停稳。2026-10-07 用户否定衣服飘动的角色动画，首页、Wearing 页与欢迎页使用定稿 3D 静态形象，不为角色添加漂浮或呼吸动作。角色承担陪伴与表达邀请，不再变成另一个语音按钮。首页下方露出最近进展与下一条日程；暂停、留出时间、先不安排会同步改变进展说明。页面与反馈的轻量过渡继续保留，并尊重减少动态偏好。

输入与五入口组成同一块安静的白色底座。输入外框固定 58pt，语音、单行文字、多行文字高度一致；中央文字区为 44pt，长文字内部滚动。编辑状态用整个圆角输入条的细线表达，不出现浏览器粗蓝色矩形 outline。键盘 Tab 导航保留可见、圆润的焦点反馈，不能全局抹掉可及性。

相机、键盘、附件保持 44pt 命中区；有文字时附件位置交叉淡入为发送。语音和文字层保留挂载，视觉交叉过渡与真实焦点同步，不等待动画才响应。五入口约 60pt 高，以图标和小标签表达用途；选中底色支持双向、可中断过渡。「聊天」使用对话气泡图标，内部 now/conversation 路由 ID 不改。

按住 220ms 后进入聆听反馈；至少 600ms 松手才进入转文字预览。上滑 64pt 进入取消区域，回到 40pt 内继续。状态与“已取消”浮在输入栏上方，绝对定位，不挤动底座；退出时保留最后文字至动画结束。路由切换、失焦、后台、离线和卸载取消待执行回调。

输入底座移到路由外常驻，五入口只替换上方内容。页面与分区内容组轻淡入/淡出；已有 Sheet、按压、提示和选中态都有退出路径。减少动态时收敛为静态或短淡入，不为每行文字安排延迟动画。新增内容动画复用项目已有 Reanimated，无新增依赖。

当前预览不调用麦克风、不执行 ASR，松手后的固定示例句明确标为「示例文字，可修改后发送」。它用于确认手势与视觉，不代表真实识别能力。共享手势控制器位于 `src/hold-voice.ts`；真实录音适配必须处理首次权限、准备录音时已松手、取消后清理临时音频、原有草稿恢复及身份切换。iPhone 系统键盘、触感和 VoiceOver 仍需签名真机验收。

新输入进入自己的当前对话，不接到无关的旅行示例后面；预览不伪造 Agent 的理解和回答。参考产品用于分析操作效率与陪伴关系，最终以 Wearing 的使用路径和真实状态作判断。

### 回看与记忆

日历与笔记在同一页切换，任务页集中显示待办和持续目标。日历图标显示设备当地日期，内容展示完整月份，支持前后月、回到今天和选日查看。今天的细边与当前选日的实底分开；有安排的日期以小点标记。预览和真实客户端共享月历，真实记录按完整年月日、跨天重叠和全天结束日排除规则筛选。任务与笔记用于查看、完成和纠正已有记录，不新增与主场竞争的聊天导流按钮。记忆显示具体内容及其来源，并允许纠正；了解用户不靠亲密度数值代替可审查的信息。

### 确认与结果

确认只呈现决定对象、必要影响、一个主动作及安静的次选。确认后的回执和业务执行完成分开表达。结果按当前问题提供可比较、可深入的内容与依据入口，不把演示旅行选择固定成产品工作流。

### 轻按与页面移动

`TactilePressable` 按下时轻缩小并降低不透明度；释放时可中断恢复。当前按下 110ms、释放 180ms，默认缩放为 0.975。操作立即执行，不等待动画结束。原生栈采用系统横向进入；减少动态时改淡入淡出。

### Sheet

标题、关闭按钮、内容与可选底部动作构成稳定结构。点击遮罩、关闭按钮、系统返回与辅助功能 escape 可退出；下拉仅由顶部抓手接管，正文保持滚动与文字手势。进入将焦点交给标题；网页 Modal 负责焦点圈定与还原，原生辅助功能焦点需要真机复核。

进入 280ms、退出 200ms，减少动态时使用 140ms 淡入淡出并取消自动位移。抓手松开未达到关闭阈值时回到原位。`Entrance` 是轻量内容过渡，不应给每一行重复添加入场动画。

**The iPhone Motion Rule.** 手势和点击先得到反馈，动画可中断且不延迟动作；减少动态时去除缩放及自动位移，页面和弹层使用轻淡入淡出。

## Do's and Don'ts

- **Do** 延续 Wearing 的色彩和真实 3D 角色，以平台字体、返回、安全区和键盘行为承载手机体验。
- **Do** 保持一个意图主场，必要的回看与纠正操作直接可达。
- **Do** 在实际写入、发送、确认和完成之间使用准确反馈；演示状态明确标注为示例。
- **Do** 分开记录源码、网页交互与 iPhone 真机验收，尤其复核大字号、键盘、手势、触感和辅助功能。
- **Don't** 把桌面手机外框、页面目录、示例时间及旅行内容升级为产品规则。
- **Don't** 把预览波形称为真实录音，或把预览日历的变化称为 Apple 日历同步。
- **Don't** 以装饰性玻璃、持续动效或层层面板代替清楚的信息与顺手操作。
