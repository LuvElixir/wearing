# Wearing 随手输入设计记录

日期：2026-10-04。适用范围：`src/wearing/web/index.html` 的快记媒体输入和生活记录原件区，以及 `capture.css`、`capture.js`；继承 `life.css`、`style.css`，品牌与既有组件以根 `DESIGN.md` 为准。此次仅补充已有 Wearing 世界，不替换设计方向。

## Overview

原话、图片和录音先留在同一条日常记录，再由用户选择让 Wearing 整理。当前记录可直接编辑，也可继续进入已有对话。钴蓝卷袖角色、奶油色面部、字标、近白页面与系统阅读字体继续适用；今天页的问候、五个目的地、书写区域和日程／清单保持原有关系。

## Colors

媒体入口默认说明灰；悬停和录音中使用浅钴蓝底与深钴蓝字。上传提示默认说明灰，后台阶段及记录摘要中的整理状态使用深钴蓝；上传失败和后台失败／中断使用问题红。原件区以正文墨灰、说明灰与细分隔线组织，没有新增品牌颜色。

## Typography

快记继续采用 `life-capture`，媒体入口和整理勾选项沿用生活辅助层级。后台阶段与原件详情采用 `capture-detail`；文件名为 13px、1.6 行高，上传提示为 12px、1.6 行高，文件说明为 12px。原话与识别内容保留换行并允许长词折行。手机媒体入口为 14px，输入文字继续为 16px。

## Layout

附件列表置于快记文字之后，媒体入口随后出现；记录类型和「记下」继续在原有操作行，可选整理项在帮助文字之后。媒体工具行与入口组以 8px 间距排列并允许换行；工具行上方留 6px，附件列表上下各留 14px。每份原件使用开放行、12px 内容间距和 `8px 0` 内边距。

在 `≤700px` 时，媒体工具靠上对齐，上传提示占独立一行；继承生活工具编辑区进入普通流的规则。原件区接在编辑表单之后，用上方细线、20px 顶部间距与 16px 内边距区分来源。冲突建议在原件之后使用另一条细线。这里没有新增固定面板或粘性定位。

## Elevation & Depth

新增区域没有投影，继续依靠白色书写面、原编辑区浅蓝色面和分隔线分层。媒体按钮继承全局 150ms 控件反馈及缓动；所有减少动态效果规则继续适用。原件折叠箭头按 `details[open]` 转向，源码未增加过渡。原件 summary、复选框、链接与按钮沿用生活工具可见焦点（3px 外描边，3px 偏移）；快记仍由整体边框表达 textarea 焦点。

## Shapes

媒体工具、方形缩略图及完整原图使用既有 12px 生活控件圆角。工具图标为 18px、1.6 线宽的圆端 SVG，折叠箭头为 16px 并沿用相同笔画。图片缩略图为 60px 方形、`object-fit: cover`；原图全宽、自动高度、`object-fit: contain`，桌面最大高度 300px、手机 380px。缩略图的裁切仅服务附件识别，原图保持比例。

## Components

- **图片与录音输入：** 「图片」打开接受 JPEG、PNG、WebP 的文件选择器，并带 `capture="environment"` 提示；「录音文件」选择已有音频。图片选择或粘贴后立即上传，同一条最多四份原件、每份不超过 15 MB。当前是网页文件输入，不据此宣称原生 App、系统分享或真实手机拍照已验收。
- **说一句：** 使用浏览器 `getUserMedia` 和 `MediaRecorder`。录音中按钮为浅蓝、文字变为「说完了」，邻近 `role="status"` 显示时长；再次点按或提交记录结束录音，离开今天页也结束录音。录音上限为三分钟。权限拒绝、浏览器不支持、空录音与录音失败均保留中文提示及已有录音文件入口。
- **上传原件行：** 文件名、保存进度或错误保留在原件行；图片有缩略图，音频有原生播放控件。上传成功显示「原件已保存」，失败保留待上传文件并提供「重试」。移除按钮具备包含文件名的可访问名称。已上传附件与整理勾选项按身份保存在当前浏览器会话中；不将其描述为跨设备或离线同步。
- **记录提交与可选整理：** 有媒体时可不填文字直接记下，文字仍可补充。默认勾选「记下后，请 Wearing 帮我整理」，可取消。提交先等待录音结束与所有上传，再保存当前记录及原件关联。未成功的上传阻止记录提交并说明原因；后台整理不阻止已保存的记录继续使用。
- **阶段反馈：** `queued` 说明原件已保存、等待整理；`extracting` 说明正在读图片或听录音；`organizing` 说明正在整理；`done` 说明已整理且原话原件仍在；`saved` 说明只保存；`failed`、`paused` 说明失败或中断但原件已保存，并显示「再整理一次」。`conflict` 明确保留用户修改，并将 Wearing 建议单独放在下方。
- **原话与原件：** 用原生 `details`／`summary`，默认为收起，summary 最小高度 44px；右向 SVG 箭头表示收起，展开旋转 90 度向下。箭头隐藏于辅助技术，summary 的文字提供名称。点击和键盘开合由原生语义管理；同一记录后台刷新保留展开状态。原话、图片文字、录音转写及原件链接共同呈现，转写明确提示可对照原录音。原图点击可打开原件，录音使用原生播放控件。
- **整理建议：** 仅在用户编辑造成冲突且有建议时显示「看看 Wearing 的整理」第二个原生折叠项，复用方向箭头与阅读样式。建议标题和正文可查看，用户输入继续保留；本组件没有新增自动采用建议的按钮。

## Do's and Don'ts

- **Do** 把原件上传、记录保存和后台整理分别交代清楚，并保留错误与重试入口。
- **Do** 在当前记录中保留原话、原件与识别文字，原图完整显示，转写允许对照原录音。
- **Do** 让原件与建议使用带可见箭头的原生折叠入口，保留键盘、焦点与刷新后的开合状态。
- **Do** 让用户手动修改优先，冲突建议单独显示。
- **Don't** 以整理完成表示 OCR、同音字、时间或用户意图已核对。
- **Don't** 将原件全页复拍中的滚动位置、粘性叠层、可见跳转链接或焦点描边当作初始页面构图。
