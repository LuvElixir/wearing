# Wearing 原生桌面设计记录

日期：2026-10-04。适用范围：`clients/desktop/frontend/index.html`、`connection.css`、`connection.js` 的连接入口，以及 `clients/desktop/src-tauri/src/main.rs` 的窗口、菜单和收起行为。品牌与已有组件以根 `DESIGN.md` 为准；这是已建立的 Wearing 世界在桌面的增量。

## Overview

桌面入口让 Wearing 随时可回到眼前。连接页先显示既有字标与卷袖头像，再说明地址、连接动作和下一步；连接成功后进入现有服务的今天、日历、清单、笔记与对话，继续使用同一份记录。

内置连接页使用标准系统窗口。它是恢复连接的安静入口；日常页面继续由现有 Wearing 网页提供，沿用原有角色、字标、视频、字体与组件。首屏方向契约位于连接页 `<body>` 开头的注释。

## Colors

页面沿用近白 `page`，输入面沿用书写白 `surface`；正文和辅助说明分别使用 `ink` 与 `muted`。主操作使用行动钴蓝 `blue`，悬停使用 `blue-deep`，输入边框使用 `line`。连接中的文字使用深钴蓝，失败使用 `danger`；状态同时以可见中文说明。

颜色继续由根设计文档的前置元数据定义。连接页没有增加品牌色或新的色面层级。

## Typography

连接页使用平台原生无衬线中文字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif`。这延续现有阅读字体方向，没有使用网页问候的展示字体子集。

| 角色 | 当前连接页实现 |
| --- | --- |
| 标题「我在这里。」 | 加粗标题（28px，行高 1.3，字距 -0.02em） |
| 说明、地址输入、主操作、状态 | 正文（15px，行高 1.7） |
| 字段标签、帮助、快捷键与关闭说明 | 辅助文字（13px，行高 1.7） |
| 字标 | 原有 SVG 轮廓（132 × 35px），不以文字重新排版 |

这些值是连接入口的层级，保留在本 surface 与组件样例中；主对话、生活工具和品牌问候继续使用已有各自层级。

## Layout

| 原生窗口 | 默认内部尺寸 | 最小内部尺寸 | 行为 |
| --- | --- | --- | --- |
| Wearing 主窗口 | 1180 × 820 | 760 × 600 | 加载既有网页；关闭请求收起主窗口 |
| 连接 Wearing | 480 × 740 | 360 × 620 | 可调整尺寸；使用普通文档流与页面滚动 |
| Wearing · 原件 | 800 × 680 | 源码未另设下限 | 由当前服务打开同源原件窗口 |

窗口值来自 Tauri 的 `inner_size`／`min_inner_size`，不是截图像素尺寸或新的响应式断点。标题栏、边框、窗口控制与菜单使用系统标准表现。

连接页单列外层最大宽度（460px），上下内边距（32px），左右内边距（24px），水平居中。采用全局 `border-box`，因此最大文字与字段宽度为（412px）；在最小窗口宽度下随可用空间缩窄。字标之后留（30px）再放原头像（112 × 112px），头像以 `object-fit: contain` 保持比例；随后依次是标题、说明、字段、帮助、一个主操作、状态与两段辅助说明。

地址字段和主操作最小高度均为（46px）。状态至少预留（26px），长错误及页脚文字允许任意长词折行。页面没有固定页脚或裁切容器；窗口缩小时，完整内容通过自然滚动读取。默认连接窗口已增高至（740px），修复复核发现的关闭说明裁切。

## Elevation & Depth

连接入口没有新增投影、遮罩或装饰运动。近白空间、白色字段与细边框建立层级，头像保留原资产材质。键盘焦点使用可见外描边（3px，偏移 3px，现有 `#93a4eb`）。源码没有为连接按钮添加按压缩放或颜色过渡；减少动态效果时滚动保持即时行为。

## Shapes

地址字段与主操作复用已有控件圆角（14px）。字段为细边框（1px）、内边距（10px 12px）；按钮无边框、内边距（10px 20px）。连接页头像与字标直接使用原资产，不裁切或重画，不把本入口的头像大小推广为全局品牌尺寸。

## Components

### Connection Form and Feedback

地址字段有明确标签，使用原生 URL 输入、必填约束、长度上限（2000）与地址自动补全，关闭拼写检查。默认地址为 `http://127.0.0.1:8765/`；启动时读取已有连接地址。验证器只接受本机 HTTP 或远端 HTTPS 根地址，具体格式限制见 `docs/native-clients.md`。

| 状态 | 可见表现 | 连接与记录关系 |
| --- | --- | --- |
| 读取设置 | 地址字段显示已保存地址；主窗口在没有设置警告时自动尝试连接 | 自动尝试不重新保存设置 |
| 正在连接 | 按钮显示「正在连接…」、禁用并降低透明度（0.65），鼠标呈等待；状态为「正在找 Wearing，记录仍留在原来的地方。」 | 先验证服务可用性，再更新当前连接 |
| 验证失败 | 问题红显示实际错误；按钮恢复「连接 Wearing」，保留可重试的字段 | 验证失败保留此前当前连接和已保存地址；输入的新地址留在字段中供修改 |
| 保存失败 | 问题红显示「无法保存连接设置。」等实际错误，恢复操作 | 保存成功前不更新当前连接 |
| 已连接 | 状态写入「已连接。」；主窗口导航至验证后的 Wearing 地址并聚焦 | 独立连接窗口关闭；进入已有服务和记录，未创建另一份记录库 |
| 页面未打开 | 问题红说明「连接已找到，但页面暂时没有打开。」 | 此错误发生在更新连接之后，不能宣称所有失败都回退至旧地址 |
| 设置无法读取 | 问题红说明实际错误及「原设置已保留，可以重新连接。」 | 原配置文件保留；当前尝试使用默认地址，等待用户重新连接 |
| 原生入口不可用／信息读取失败 | 分别说明「请从 Wearing 桌面应用打开这个入口。」或「连接信息暂时没打开，可以再试一次。」 | 只记录当前入口状态，不据此暗示后台任务变化 |

状态区域使用 `role="status"` 与 `aria-live="polite"`。成功文字是导航前的短暂反馈，不是另一块常驻完成卡片。按钮、字段与错误文字映射既有材料；本页的尺寸、禁用透明度和焦点偏移是组件的局部实现。

### Native Menu and Window Presence

Wearing 菜单与托盘提供「打开 Wearing」「记一下」「连接设置…」「退出桌面端」；系统编辑菜单保留撤销、重做、剪切、复制、粘贴和全选，窗口菜单保留最小化与「收起窗口」。不从系统菜单外观抽取品牌颜色、圆角或字体 token。

「记一下」唤起主窗口并向已有网页投递固定快记事件；未连接时先保留该意图，服务页面加载后再投递。主窗口关闭时收起，并发出窗口隐藏事件。退出客户端只退出桌面界面；后台任务仍由已有服务管理，暂停事项在 Wearing 内操作。

快捷键说明由注册结果决定：Mac 显示「⌘ ⇧ 空格」，其他平台源码配置为「Ctrl + Shift + 空格」；注册失败时显示「快捷键暂时被占用，可以使用菜单里的『记一下』」。同一组合也作为原生菜单加速键。注册、前台菜单加速键与后台全局按键分别记录，注册成功本身不能代替触发验收。

## Do's and Don'ts

- **Do** 复用现有字标、头像和阅读材料，让用户知道正在连接的仍是 Wearing。
- **Do** 将实际连接进度、错误与重试写成可见中文，并保留键盘焦点和完整页脚的滚动可达性。
- **Do** 让连接成功回到现有服务与同一份记录，保持桌面快记与网页编辑之间的连续性。
- **Do** 分别记录快捷键注册、菜单触发和真实全局按键触发的证据。
- **Don't** 将本窗口尺寸、标题字号、局部焦点偏移或禁用透明度当成所有 Wearing 页面的全局规则。
- **Don't** 将收起或退出桌面客户端表现成后台事项已暂停。
