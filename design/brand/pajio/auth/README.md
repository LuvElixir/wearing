# Pajio 登录体验

2026-10-10 用户选择 Product Design 第 2 张方案，图源为 `exec-d5ecd0d7-0a10-4401-a9df-0eff9f92f199.png`。登录由字标、标题、入口导航和表单组成，使用平面暖白或石墨底，不加入角色大图、漂浮卡片或装饰动画。

邀请码 → 创建账号 → 进入产品在原生 App 内完成；已有账号保持系统标准 OIDC 安全认证。网页入口与 Keycloak 使用相同字体、间距和状态语言，Keycloak 继承官方认证模板，不替换 MFA 或密码行为。

## 状态与输入

- 当前入口：强调文字与短下划线。焦点：独立 2px 轮廓与偏移。按下：短暂颜色变化。它们可同时存在。
- 校验错误保持输入并展示就地文本；重试和不确定结果恢复遵守真实状态机。
- 密码长度由服务器按 Unicode code point 判断，不使用会按 UTF-16 截断的 HTML maxlength。脚本只切换可见性与 pending 状态，不读取或记录密码文本。
- 控件最小 44pt，主要字段和按钮 52pt；系统字体支持中文；减少动态时不使用位移动效。
- 设计图自动生成的“使用即表示同意”不是已批准法律文案，没有照搬到实现。

## 共享规范

数值来源为 `../interaction-tokens.json`，App、Web、Desktop 和认证页同步核验。选中语言全产品统一，radio、checkbox、switch、tab 保持正确语义。详细盘点见 `login-selection-audit-20261010.md`。

字标复用已批准 `src/wearing/web/pajio-wordmark.svg`；此版本无需新位图。旧生成素材仅保留在本机生成历史，不随登录发布。

## 对照检查

目标图按 390×844 归一化，与同尺寸真实页面放在同一比较输入中检查。首次发现字标过大及表单整体偏下，已修正字标为 56×24、标题及导航间距。32px 主标题和窄屏 24px 是图稿的有意尺度；12px Keycloak 圆角的 !important 只是覆盖官方样式的优先级，不新增另一种半径。
