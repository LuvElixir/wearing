# Pajio

2026-10-07 · 正式名称与已确认睡衣小熊方向的数字品牌文件。

Pajio 是产品名，也是用户直接称呼助手的名字；中文界面同样使用 Pajio，不另外强配中文译名。描述为「个人 AI 助手」。品牌主张：**你先休息，这件事我来。** 日常输入文案：**你说，我来做。** 后台运行、完成和通知均取实际能力与回执，不从标语推导功能承诺。

## 识别系统

- **字标**：`wordmark.svg`，从已选 `wordmark-custom-v2.svg` 的五个原创闭合字形路径导出；P、a、j、i、o 分别绘制，字腔使用 even-odd 填充，没有字体、文字元素或图片依赖。标准写法 Pajio，不添加句号。`OFL-Nunito.txt` 仅为历史设计留档，当前字标不使用该字体。
- **单星**：`symbol.svg`，延续用户选定的单颗四角星。用于紧凑签名、简洁模式和现有启动画面；导航继续使用有功能含义的图标。单星不代表尚未定稿的 App 图标。
- **组合**：`signature.svg`。同时提供黑色与反白版。字标最小建议宽度 72px，组合标最小 104px，单星最小 16px；小尺寸不塞入字标。
- **留白**：至少单星宽度的四分之一；与正文并排时按文字视觉中线对齐。保持比例，不拉伸、不加外发光、不套多颗星。
- **应用图标**：用户于 2026-10-07 选定 C「被窝小熊」。母版为 `app-icon-c-master.png`，生产方图 `app-icon.png`，尺寸与哈希见 `icon-manifest.json`。使用内置 image_gen 整理母版，sips 机械缩放。`app-icon.svg` 是有标注的栅格包装；原创字标继续使用 `wordmark-custom-v2.svg`。旧候选均被本次选择取代。
- **角色**：采用 `design/character/pajama-bear-20261007/selected-character-base.png` 的圆润比例、奶茶色毛绒与小型刺绣嘴。生产图为 `clients/mobile/assets/bear/` 八套透明 PNG。默认雾蓝条纹，保存的个人选择优先。

## 日间与夜间

阅读区以 `clients/mobile/src/appearance.ts` 为唯一数值来源。日间浅灰与白色分层，夜间石墨与深灰分层。品牌展示可使用奶油、雾蓝、燕麦等服装色；文本区保持清楚的对比度。首次跟随系统，用户可主动选择浅色或深色。

正文使用系统字体；中文主要正文 17pt，长文以阅读宽度和行距控制密度；辅助内容不靠低对比或过小字号隐藏。颜色不单独承载成功、异常或等待的含义。系统大字号保持可读，功能点击区至少 44pt。

小熊是身份与陪伴触点，不在每个空白处重复出现。欢迎、助手进展、衣橱可以展示，任务结果把空间留给内容。八款服装共享脸、比例与材质基准。不会通过小熊睡着来暗示任务结束。

## 动作与文字

没有常驻角色循环动画。短按压、局部状态变化尊重减少动态效果；不以假进度、估算倒计时表现执行。用户离开后返回，优先看到真实需处理事项、进展和结果。

输入、保存、接收、执行、结果返回是不同状态。错误说明能做什么恢复，技术堆栈留在诊断。长按语音先得到可编辑文字，发送才交给助手。

## 交付与复现

`build.py` 直接读取原创字形主文件，导出全路径 SVG、透明字标 PNG、单色与反白版本及组合标，不再从 Nunito 或其他字体生成。当前仅重建已定字标与单星：

```sh
uv run --no-project --with cairosvg --with pillow python design/brand/pajio/build.py --wordmark-only
```

完整构建会检查 `icon-selection.json`；图标尚未选定时直接拒绝执行，不会把现有候选重导出成正式资产。本轮暂停更新品牌 ZIP，等待图标方向明确。当前旧 ZIP 不包含最新字标与最终 App 图标，不作本轮最终交付。

`index.html` 是日夜与衣橱可交互的品牌板，不连接用户数据；图标定稿前仅展示已确认的字标、单星与角色。`preview.py` 仅在回环地址按白名单提供品牌资产与既有小熊图片。

App 的显示名称及权限说明改为 Pajio；现有 bundle ID、数据目录、HTTP 头、协议名称和穿搭键保持兼容。技术名称 `wearing` 并非用户可见品牌。正式安装包需重新构建，Expo Go 不会替换自身应用图标。名称、字标与资产已落地不代表已发布应用商店或已完成商标注册。
