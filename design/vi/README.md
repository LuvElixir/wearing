# Wearing 品牌与视觉工作区

更新：2026-09-30。产品关系以[产品定义](../../docs/product-definition.md)为依据。产品名称确定为 **Wearing**，用户已选择第 1 个钴蓝外套、奶油色头部、卷袖动作的角色方向。“你的个人 Agent”作为中文定位说明。

## 最新共识

用户明确的关系是：“属于我的行动者，同时也是延伸出去的另一个我。”产品通过持续理解用户、独立推进事务、带回真实结果来体现这种关系。

用户希望学习优秀 Personal Agent 的亲和力与体验，例如 Muse 的可爱 IP。舒适、有吸引力的外在体验与产品哲学兼容；希望用户愿意尝试，并因实际能力持续使用。该路径是设计目标，留存效果仍需实际验证。

## 已选方向与制作规范

用户反馈：“我最喜欢第 1 个，太对味了，但就是标志图形还得简洁些。”因此保留完整角色，将独立小标志简化为头部、双眼与折领。

- [已选概念板](wearing-round-01/01-cuff.png)：角色比例、钴蓝外套和卷袖动作的视觉依据。
- [简化标志 PNG 草稿](wearing-selected/mark-simple-v1.png)：用于确认小尺寸识别方向，尚未整理为正式 SVG。
- 主色钴蓝 `#4562DC`，暖白 `#F6F3EC`，深灰 `#25282C`；浅蓝只用于少量内衬细节。这些是设计色值，生成图的实际像素需在正式制稿时统一。
- 完整角色保留材质与柔和光影，使用 PNG / WebP；主标志、单色标志和正式字标后续制作干净 SVG 路径。
- 小标志保留最少辨识元素。正式制稿检查 16/24/32 像素、浅深背景和单色效果，再导出应用图标。
- 正式字标的字体/字形源稿、授权记录、标准间距和状态动画尚未制作，不把概念板中的文字或位图当作完成资产。

- 以有性格的角色 IP 作为主要识别，Wearing 字标、中文定位、头像与状态动作保持一致。
- 建议性格：亲切、机灵、有主见。通过具体反馈和行动表现性格。
- 使用 Wearing 作为品牌名，中文定位说明保持直接易懂，实际使用中的个人昵称可以另设。
- 产品使用统一的品牌名称，并允许用户给自己的 Agent 设置昵称。此为设计建议。
- 角色在对话与任务中持续出现，分别表达倾听、思考、执行、等待用户和完成。重要状态始终同时提供清楚文字。
- 界面保持安静：充足留白、稳定文字层级、一个主识别色。把表现力集中在角色动作和少量关键反馈上。
- 使用状态图来评估 IP，而不仅评估静态形象：头像尺寸、接到任务、执行中、需要接管、完成结果。
