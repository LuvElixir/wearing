第一次连接，需要准备什么？

先在兼容的 Mac 或 Windows 电脑上安装 Hermes 并配置模型。按官方说明设置以下环境变量，再运行 Gateway。

API_SERVER_ENABLED=true
API_SERVER_KEY=你的独立连接密钥

hermes gateway

工具权限与设备控制需要在执行电脑上验证。

录屏列表里找不到 CuaDriver

在 macOS 的「录屏与系统录音」上方列表点击 ＋，按 ⌘ ⇧ G，粘贴下面的应用路径。选中 CuaDriver 后点「打开」，再开启它的开关。

驱动保存在 Wearing 的运行目录，不一定会出现在「应用程序」中。无需开启下方「仅系统录音」。

    
接管时会发生什么
你可以随时接管。Wearing 会停止新的电脑读取和操作；已发出的点击可能仍需片刻返回。交回后会重新观察窗口再行动。
电脑操作复用 Hermes 与 Cua Driver。当前接入的是运行 Wearing 的这台电脑。Mac 需要 CuaDriver 的辅助功能和屏幕录制权限；Windows 接入沿用同一驱动，但尚未完成真机验收。

  

  
你的手机

  
连接 USB，解锁手机，并允许 USB 调试。

  
每部接入的手机都可以单独使用、暂停和恢复。中文填写支持可识别的 Android 原生输入框。

  

  

  

  

  
手机没有出现授权弹窗
打开手机的开发者选项与 USB 调试，保持屏幕解锁后重新插拔数据线。小米设备若能看画面却不能点击，还需检查“USB 调试（安全设置）”。
Android 通过 USB 调试接入，无需插 SIM 卡或 root。不同品牌的附加授权会在实际操作时确认。暂停会拦住后续动作，已发出的操作可能仍需片刻返回。

  
其他 Android 和 iPhone 呢？
Android 使用通用调试协议，接入后逐项确认读取、点击、滑动和输入。当前真机验证为小米 6X（Android 9）。iPhone 控制连接器尚未接入，需要单独的信任、开发者模式及签名配置。
