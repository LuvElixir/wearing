## 本轮已关闭问题

1. **设置卡背景没有铺满。** 初始截图中，SVG 渐变只覆盖内卡左上部分，右侧和下方留空。背景现置于覆盖完整卡面 bounds 的独立绝对定位层，最新 `settings.png` 确认渐变完整铺满，圆角裁切正确。
2. **今天页两种触摸行不足 44 pt。** `TodayPanel.tsx` 的日程标题行和日程条目现均为 `minHeight: 44`，符合本次设计约束。此项通过源码确认；没有声称完成真机触摸测量。
3. **非聊天首页有重复页头层级。** 今天、任务、记忆、我的已移除额外公共工具栏，主标题上移，第一屏内容更完整。聊天保留进展 / 搜索 / 设置，次级页保留返回；已逐张确认最新截图。

## 后续事项与验证边界

- **P2，已有内容问题：历史回复的附件标记。** `chat.png` 和 `search.png` 中，一条旧回复仍显示未解析的 `MEDIA:` 本机文件路径，用户无法直接看到对应图片。后续应将可访问媒体解析为附件或给出明确的不可用状态；本轮没有改写历史回复来隐藏问题。它属于附件呈现问题，不是此次渐变、气泡和导航改版引入的回归。
- **P3，可选一致性收尾：任务页标题。** 任务页仍使用 `Mobile.tsx` 的 30 pt / 600 标题，今天、记忆、设置使用 34 pt / 500。后续可统一主页面标题样式，减少切换时的字号和字重变化。
- 本次没有验证实体 iPhone 的麦克风、照片、日历和位置授权，也没有验证软键盘完整弹出、大号辅助文字、横屏、VoiceOver、深色外观、所有文件夹深层页面或云端授权流程。不能据此宣称这些路径已验收。

## 源码检查

最终截图复核后运行：

- `npm run typecheck`：通过。
- `./node_modules/.bin/eslint src --no-cache`：通过。

`npm run lint -- --no-cache` 的 Expo 入口被当前机器全局 `npx` 的 ESM 配置错误挡住（`require is not defined in ES module scope`），因此使用项目本地 ESLint 检查源码。直接 lint 整个目录会把 `dist-all` 打包产物纳入并产生构建代码规则错误；没有把该产物扫描结果当作源码回归。
