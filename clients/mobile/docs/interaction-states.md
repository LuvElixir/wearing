# App 交互状态与原生加入页

2026-10-10，按用户选定的第二张 Product Design 参考实施。颜色源为 `design/brand/pajio/interaction-tokens.json`；原生 `src/appearance.ts` 镜像该契约，避免扩大 Metro 读取范围。

## 呈现规则

- `experience/selection.tsx` 的 `Choice`：单选使用 radio，多选使用 checkbox；轻底色与明确标记同时呈现，选中不是焦点边框。支持行、chip 与衣橱卡片。
- `Segment` 与底部导航：强调文字、短下划线；不叠加选中卡片阴影。月份日期保留今天的轮廓和选中日期的独立底色。
- `StateSwitch` 保留系统 switch 行为，统一使用语义色；开关只是原有 draft 或真实回执的呈现，组件不保存数据、不调用网络。
- `TactilePressable` 单独处理焦点环、按压、禁用；网页预览明确转发 checked/selected 等 ARIA 状态。减少动态效果时取消缩放与动画切换。

## 覆盖入口

主题；底部导航；日历/笔记、任务/清单/定时、技能和收藏页签；月份日期、日历来源与重复规则；新手角色/应用/兴趣/偏好；衣橱；身份；捕捉类型；任务清单及完成勾选；结果选择；导入聊天作者；搜索筛选；反馈类型及健康记录范围；简报来源、数量、补做时间与开关；系统日历/提醒列表；系统同步来源；飞书授权范围；设备与手机能力、私密交还确认；记忆启用与安静时段；独立交互预览。

衣橱选中仍表示正在预览；“就穿这套”单独保存。权限/记忆/设备选择保留原先保存、确认与错误处理，不把轻底色当成服务已确认。模型下拉框和持续目标/定时安排等保留面板由 Core 提供的 WebView 页面呈现；`src/wearing/web/mobile-host.css` 已镜像同一契约，覆盖搜索当前命中、复选项、主按钮、焦点、按压与禁用。网页保留页签的父容器和定时表单也显式使用主题底色，避免夜间浅字落到旧的固定浅色背景。原生日历使用原生共享组件；若保留页面打开网页日历，Monarch 的颜色别名也按同一契约呈现。

## 原生加入

平面布局包含 SVG 字标、标题、邀请码/已有账号页签、单输入和主操作。邀请码验证、账号设置、注册结果恢复全部使用原生控件；已有账号仍使用系统安全窗口的标准 OIDC。界面没有新增或默认接受任何法律条款。

密码和邀请码不持久化。注册返回 completed 也不直接宣称登录；仅在会话交换并经校验、私有凭据和本机元数据保存成功后进入 App。未知请求查询原操作，不重放注册或一次性交换。取消发生在 SQLite 最后写入/提交等待期间时，恢复旧账户元数据并移除本次新凭据；真实 SQLite 测试覆盖该竞态。

## 验证边界

代码有 day/night 契约比对、真实 RN Web SSR 的 radio/checkbox/tab/switch 语义验证、注册故障与本机事务测试。隔离预览使用实际原生组件与合成服务状态，不是真实注册验收。最终手机画面、键盘行为和新包安装由主任务另行验收，本文不据源码或预览宣称已经部署。

原生源码冻结为 40 个运行时文件，完整 846 项测试、TypeScript 与 ESLint 通过。嵌入页样式另有 14 项定向回归（含实际受控主题桥执行）和 CSS 解析检查；Web/认证页已有色值与 canonical 逐项比对通过。该 CSS 从 Core 远程加载，不进入原生 source-sync 清单，服务器样式部署需另行完成；这些代码检查不代表真实注册或手机运行已通过。
