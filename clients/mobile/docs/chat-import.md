# 选定聊天导入（App）

## 入口与数据流

- “我的/设置”及聊天“＋”内的“导入选定聊天”，支持系统文件选择器选一份 ZIP/TXT。
- 分享收件箱收到 ZIP/TXT 后，先点“预览为微信选定聊天”。ZIP 不允许走普通记录或 workspace 上传链路。
- 首次打开只在本机解析。展示会话文件名、作者、来源时间范围和消息正文，20 条一组展开；可选“哪一位是你”，默认不指定。点击“确认导入”才 POST 结构化文字到当前身份的 `/api/chat-imports`。
- 归档图片、语音、视频及文件仅在手机显示附件名称/数量为“未导入”。没有解压附件到文件系统，没有上传附件字节，也不猜它们属于哪条消息；提交消息的 `attachments` 为空。
- 已导入列表来自服务端。点击批次标题可读回来源消息；整批移除使用服务端 DELETE，保留明确的二次移除界面。既有生成对话/结果可能含引用，界面说明它们需单独删除。

## 支持格式与证据

格式按第三方 WeChatBridge 固定源码版本 `0b00e3f89ace0e8f5d9c17478b2c966d0e2b890e` 的 `macos/Sources/WeChatBridgeCore/WeChatForward.swift` 中 `WeChatTranscriptRecord` 核实：

```text
·合成作者甲
2026年10月9日 09:00
这是一条合成消息。
·合成作者乙
2026年10月9日 09:01
这是第二条合成消息。
```

来源：<https://github.com/freestylefly/WeChatBridge/blob/0b00e3f89ace0e8f5d9c17478b2c966d0e2b890e/macos/Sources/WeChatBridgeCore/WeChatForward.swift>。

这是社区解析器中的实际格式，不是腾讯对 iPhone/Android 导出格式的兼容承诺。本实现只验证合成数据；没有读取真实微信账户，尚未验收各版手机微信分享入口及实际载荷。

UTF-8（含开头 BOM）、LF/CRLF 支持；非法 UTF-8、UTF-16/GBK、未知格式、无效日期拒绝，不替换乱码或猜作者。原时间文本保留，不推测时区。ZIP 优先唯一 `聊天记录.txt`；否则要求唯一 TXT。多个候选不自动选最大的文件。

## 本机持久与恢复

- 预览正文存在应用私有 SQLite，键包含 endpoint + owner + tenant + identity，不发送给网络。退出页面后可继续；“移除本机预览”会清正文，分享来源同步清本机副本。
- 确认时先持久化不可变请求与随机稳定 `request_key`。重试先 GET 原编号的回执；不存在时才 POST 原请求。待核对时不能改作者、文件或普通分享用途。
- 回执必须匹配当前 identity 与 request key。回执为 `deleted` 不会重发恢复。成功先清正文、保留无正文待核对编号；分享源删除完成后再清该编号，因此中断可继续清理。
- 退出账户会冻结该连接的导入工作，清该账户所有身份的本机预览及请求正文；仅保留无正文请求编号供重新登录后查询未知结果。若服务未收到且本机正文已清除，要求重新选文件，不猜一个替代请求。
- 已绑定、但解析失败或中断而尚未写入预览的分享副本，也随退出清除。文件删除失败保留清理索引，退出重试仍能清理。
- 账户注销复用既有 owner 范围的 SQLite 清理与写入栅栏，删除本机预览、待提交正文和归属账户的分享文件；其他账户的数据保留。
- 原文件/照片库和外部 provider 文件不删除。文件选择器生成的本机 cache 副本在读取完成、失败或取消时清除。

## 边界

- 原始文件 ≤ 15 MiB；聊天 TXT ≤ 384 KiB；单消息正文 ≤ 16 KiB；最多 500 条消息、50 位作者。
- ZIP 最多 500 项，声明展开总量 ≤ 30 MiB，压缩倍率受限；拒绝加密、ZIP64、未知压缩法、路径穿越、链接、重名/大小写与 Unicode 路径别名、嵌套压缩包、目录/本地头不一致和越界区块。
- 只展开聊天 TXT，在 1 KiB 压缩块间让出 JS 线程；核对真实输出大小和 CRC。附件不展开。
- 结构化请求 ≤ 512 KiB。后端另行校验消息、容量及认证归属，客户端不能提交 owner。
- 不自动创建任务、写用户人格、发消息或执行聊天内的指令。

## 验证

`npm test` 包括纯解析边界、合成 ZIP、预览无网络、身份隔离、丢失回执恢复、删除回执防重放、分享 ZIP 禁止普通上传、Android provider 收件和退出清理 VM 测试。原生分享扩展和 Android MIME 变更需要重新构建安装包；旧二进制仅能测试文件选择器路径。

SDK：Expo 57；ZIP 依赖 `fflate`，通过 `node node_modules/expo/bin/cli install fflate --npm` 安装。TypeScript 与 `node node_modules/eslint/bin/eslint.js src` 已验证。
